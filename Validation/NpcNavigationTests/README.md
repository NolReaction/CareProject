# Проверки навигации NPC

```sh
dotnet run --project Validation/NpcNavigationTests
```

Собираются реальные `IntercomNavGrid` и `IntercomNpcNavigation`. Для компонента
используются маленькие замены иерархии, времени и Bounds; физика Unity не выполняется.

Проверки: запрет срезания углов; объезд стены; недоступная цель; ограниченная
проекция; 1200 сравнений с независимым BFS на случайных картах; маршруты по
`DistrictLayout.json`; исчезновение и восстановление коллайдера; общий бюджет
двух запросов в кадр; пауза; отсутствие новых выделений памяти в повторных запросах.

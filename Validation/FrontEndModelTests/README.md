# Модели главного меню

Проверяются настоящие IntercomFrontEndState и IntercomFrontEndLayout:
навигация, возвращение домой, отказ от некорректного состояния, общие границы
отрисовки и нажатий, безопасные зоны, портретный и альбомный экран.
В набор входят небольшие окна, экран с вырезами и детерминированные разные размеры.

Запуск: `dotnet run --project Validation/FrontEndModelTests`.
Это чистые модели без Unity; реальное отображение и ввод проверяются отдельно.

# Проверки здоровья и поражения игрока

Запуск из корня проекта:

```sh
dotnet run --project Validation/PlayerVitalityTests
```

Тесты собирают настоящий `IntercomHealth`, `IntercomHealthState`,
`IntercomPlayerVitality` и контракт урона. Небольшие замены Unity моделируют
компоненты, события, активность объектов, время и ссылки между ними.

Проверяется:

- Некорректный урон, иммунитет, пауза, отключённый и погибший получатель.
- Фракции, урон самому себе и источник на дочернем объекте.
- Короткая неуязвимость героя по игровому времени; две пули пистолетов
  продолжают повреждать NPC в одном кадре при нулевом иммунитете.
- Однократная смерть и сброс здоровья из обработчика события без устаревшего
  события смерти для уже восстановленного персонажа.
- Остановка управления, стрельбы и беговой анимации при смерти; повтор без
  изменения глобальной скорости времени.
- Различие настоящего возврата на старт, смены фокуса и отмены ввода.
- Сохранение исходно отключённых компонентов после смерти, отключения и повтора.
- Переназначение ссылок: старые блокировки освобождаются, новые учитывают
  исходные флаги, события старого здоровья больше не управляют новым персонажем.

Последний изолированный прогон: 175 проверок успешно.
`Validation/Results/V8/PlayerVitalityTestsResults.json` содержит результат запуска;
общая сводка V8 собирается отдельно.

Это не Play Mode. Unity не исполняет здесь Animator, физику, GUI и автоматические
вызовы жизненного цикла; тестовый сценарий вызывает нужные переходы явно.

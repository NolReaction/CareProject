# Переезд ресурсов пистолетов

`dotnet run --project Validation/AssetOrganizationTests` исполняет производственный
`IntercomAssetOrganization` и `IntercomAssetCatalog` с небольшой файловой заменой
Unity AssetDatabase. Нужен .NET SDK 8+.

13 проверок: первый ZIP, повторный запуск, повторное наложение ZIP, изменённый старый файл,
изменённый importer, отсутствующий оригинал, ссылка на временную копию, частичный переезд,
конфликт назначения, пользовательское перемещение по GUID, сохранение ссылок и запрет
перехода за пределы пути проекта. Дополнительный отчёт `AssetOrganizationV4Review.json`
проверяет семь настоящих ресурсов: исходные GUID/байты сохранены, дубликатов GUID нет.

Это проверка алгоритма с файловыми заменами API. Реальный импорт Unity и AssetDatabase
проверяются отдельно после открытия проекта.

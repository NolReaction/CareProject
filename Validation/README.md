# Проверки CareProject

Все 11 самостоятельных проектов запускаются одной командой из корня проекта:

```sh
python Validation/run_checks.py
```

Нужны Python 3 и .NET SDK 8 или новее. Можно указать путь:
`python Validation/run_checks.py --dotnet /path/to/dotnet`.
Отдельный проект: `dotnet run --project Validation/GroundFeedbackLifecycleTests`.

Проверяются направление и темп движения, опора жёстких ног, калибровка подошв,
сбросы ввода/оружия, жизненный цикл звука, перекрытия камеры и выбор попадания пули.
GroundFeedbackLifecycleTests компилирует полные классы GroundFeedback и Motor с
зависимостями и узкими заменами Unity API. Он проверяет старые сохранённые маркеры,
позднее назначение контроллера, восстановление позы и отсутствие измерений каждый кадр.
Это также выявляет несовместимый набор старых GroundMath/Motor и нового GroundFeedback.

`RepairReview.json` фиксирует проверки этой сборки относительно коммита `825ee46`.
Четыре отчёта `Ankle*.json` относятся к уже выполненному исправлению осей стоп:
исходник и FBX в этой сборке сохранены без повторного экспорта. Исторические отчёты
от прежних скелетов и старые сгенерированные `results.txt` удалены.

Проверки используют .NET, численные модели и тестовые замены движка. Они **не**
подтверждают компиляцию Unity, работу PhysX, смешивание Animator, отрисовку или звук.
Unity Editor здесь недоступен. Проверка в редакторе и на телефоне описана в
`MOBILE_TESTING.md`; её нужно выполнить после импорта проекта.

Локальные результаты в `Validation/Results`, `bin` и `obj` исключены из Git.

# Проверки структуры

`python Validation/check_architecture.py` проверяет разложение кода по
модулям, отсутствие Editor API в обычном runtime, независимость чистых моделей,
целостность `.meta`/GUID, пути исходников автономных проверок и стартовой сцены.
Именованные ссылки навигатора проверяются и по GUID, и по документированному пути.
Скрытые временные файлы с точкой в начале имени не считаются ресурсами Unity.

`python -m unittest discover -s Validation/ArchitectureTests` проверяет сам
контракт на повреждённых временных примерах. Реальный Unity importer и сборка
движка в этих проверках не запускаются.

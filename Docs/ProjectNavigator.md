# Навигатор проекта

Открой **Tools → CareProject → Start Here**. Окно ведёт к учебной сцене,
карточке пистолетов, позам, модели и Animator героя, настройкам ударника,
миссиям, звуку, планировке двора, свету и документации.

Кнопки выбирают ресурс в Project/Inspector. Поиск идёт по GUID, поэтому
перенос внутри Unity с сохранением `.meta` сохраняет переход к ресурсу.
Кнопка открытия сцены использует стандартный запрос сохранения текущих правок.
Само открытие навигатора не пересобирает сцену и не генерирует модели.

«Проверить ссылки разделов» проверяет основные точки входа. Это проверка
наличия ресурсов, а не запуск игровых сценариев. Папка автономных проверок
открывает `Validation` вне Assets.

`IntercomProjectPaths` содержит названия, GUID и канонические пути.
`IntercomAssetCatalog` отвечает за кешированный поиск ресурсов.
`ProjectAssetsV13.json` хранит сопоставление известных идентификаторов и путей;
его имя сохранено как служебная часть текущей структуры.
Изменение проекта через `EditorApplication.projectChanged` сбрасывает кеш.

Полный проект открывается непосредственно из Unity Hub. Старые миграции,
запуск CMD и автоматическая очистка прежних версий для него не нужны.
Текущие правила работы: [DeveloperGuide.md](DeveloperGuide.md).

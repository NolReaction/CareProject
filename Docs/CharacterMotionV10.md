# Движение и реакция корпуса V10

У робота короткая жёсткая нога без колена. Поэтому «человеческий» бег с высоким
подъёмом таза потребовал бы менять конструкцию или растягивать ногу. Здесь
выразительность добавлена к верхнему корпусу и плечам; ботинок остаётся на своём
подшипнике, опора и поворот стопы работают прежним способом.

Корпус теперь делает один плавный подъём за пару шагов, с небольшим встречным
поворотом плеч. Это намеренно более медленный ритм, чем частые касания коротких
ног: мы не усиливаем каждое касание новым толчком камеры или всей модели.
Подъём — работа подвески корпуса, а не настоящий прыжок капсулы. Столкновения,
камера и положение подошв от него не меняются. При остановке подвеска успокаивается.

Руки в свободном беге немного подняты; плечи качаются в противофазе, кисти чуть
запаздывают. При стрельбе, поднятии пистолетов и перезарядке действуют соответствующие
оружейные позы. Добавка бега не остаётся на руке в момент выстрела. У стены она
уступает место прижатым рукам. Позиции и масштаб костей рук не меняются.

Вся анимация использует фактическую скорость после столкновений: при упоре в
стену корпус не продолжает изображать бег. Это не независимый «синус от времени».
Поворот на месте продолжает пользоваться существующими опорными шагами.

## Где настраивать

Выбери Robot в сцене.

| Компонент и поле | По умолчанию | Что меняет |
| --- | --- | --- |
| Ground Feedback → Walk Bounce Height | 0,012 м | Подъём подвески при небольшом отклонении стика |
| Ground Feedback → Run Bounce Height | 0,034 м | Целевая высота подъёма на полном ходу |
| Ground Feedback → Stride Counter Twist | 3,6° | Встречный поворот плеч |
| Ground Feedback → Gait Blend Seconds | 0,16 с | Плавное включение подвески |
| Character Animation → Running Arm Lift | 16° | Насколько подняты расслабленные руки |
| Character Animation → Running Arm Swing | 11° | Амплитуда качания каждого плеча |
| Character Animation → Running Wrist Follow | 3,5° | Вторичное движение кистей |
| Character Animation → Running Arm Blend Seconds | 0,14 с | Вход и выход добавки рук |

Это дополнительные настройки. Сохранённые параметры старого опорного решателя,
позы оружия, модель и клипы FBX не заменяются.

Реакцию урона публикует `IntercomPlayerHurtFeedback`; `IntercomGroundFeedback`
накладывает её там же, где уже находится подвеска корпуса. Два разных скрипта
не перетягивают одну кость друг у друга. После следующего Update исходная поза
Animator восстанавливается, поэтому повороты не накапливаются.

## Проверка

Автономные проверки исполняют производственный C# с узкими заменителями Unity.
На 30/60/120 кадрах/с проверены возврат рук, первый выстрел, остановка,
снятие фокуса и отключение компонента. Измеренные исходные позы и реальные точки
подошвы используются для проверки сохранения длины ноги, опоры и проскальзывания.
Отдельно проверена передача реакции урона единственному владельцу корпуса.

При 60 кадрах/с добавленная подвеска имеет размах около 1,63 см на 0,7 м/с
и 2,27 см на полном беге. Это измерение алгоритма, а не запись Unity.
Движок Unity, кожа модели, реальные неровности и восприятие с игровой камеры
в этой среде не проверялись. После импорта особенно посмотри движение назад,
резкую остановку и стрельбу на бегу. «Идеальность» анимации этими тестами
не измеряется; следующий художественный шаг — смотреть запись игрового движения.

# Визуальный стиль CareProject: спокойная палитра V5

Цель — объёмный мультяшный промышленный двор с понятными крупными формами.
После проверки V4 на скриншотах из Unity убрали избыточную насыщенность окружения.
Робот сохраняет прежние текстуры; цвета двора теперь ближе к его приглушённой окраске.
Это основа художественного направления, которую ещё нужно оценить в движении в Unity.

## Что уже изменено

- Большие поверхности спокойные: почти нейтральный асфальт, серо-зелёная техника,
  серо-синие крыши и светлый тёплый серый бетон.
- Разметка стала охристой, контейнер — пыльно-терракотовым. Цветные мишени остаются
  различимыми, но больше не выглядят ярче всех деталей персонажа.
- Общий усилитель насыщенности отключён: saturation +8 → 0, exposure +0.05 → 0.
  Солнце чуть нейтральнее, синий оттенок рассеянного света уменьшен.
- На поверхностях вместо частого шума появились мягкие широкие изменения цвета.
  Мелкая грязь не должна мешать увидеть противника или край укрытия.
- Скосы расширены, а их освещение плавно переходит в плоскости.
  У цилиндров и труб сглажены боковые нормали; плоские торцы остаются плоскими.
- Жёлтые пластины бетонного блока увеличены для чтения из игровой камеры.
- Сохранили мягкие скосы, сглаживание цилиндров, матовые поверхности и контактные тени V4.

Это реальные сохранённые mesh, материалы и текстуры. Геометрия не строится на каждом кадре.
Число треугольников, материалов и модулей не увеличено. Внешние габариты модулей,
планировка и формы столкновения сохранены.

Мультяшность задаём прежде всего силуэтом, крупными читаемыми деталями, округлёнными краями
и анимацией. Для новых объектов берём цвет из соседнего материала сцены. Очень яркий цвет
оставляем для коротких эффектов выстрела, урона и важных игровых подсказок.

## Где менять внешний вид без программирования

| Хочу изменить | Где искать в Unity |
| --- | --- |
| Цвет бетонных блоков | `Assets/IntercomMVP/Art/PrototypeEnvironment/Concrete.mat` |
| Цвет стен и бочек | `BlueGrey.mat` в той же папке |
| Цвет крыш | `Roof.mat` |
| Цвет контейнера | `Orange.mat` |
| Разметку и жёлтые детали | `Paint.mat` |
| Картинку поверхности | Подпапка `Surfaces` |
| Саму геометрию | Подпапка `Modules` |
| Контраст и насыщенность | `Assets/IntercomMVP/Settings/TutorialDaylight.asset` |
| Солнце и его тень | Объект `Sun` в сцене |
| Контактное затемнение | `IntercomRenderer.asset` → `Tutorial Contact AO` |

Общий материал изменит все использующие его объекты. Для индивидуального объекта
сначала сделай копию материала и назначь её нужному Renderer.

Команда **Tools → Intercom MVP → Apply Tutorial Daylight** подключает свет V5 к открытой
сцене. Она сохраняет ракурс камеры, но заменяет её настройки света и постобработки.
После команды сохрани сцену.

## Как готовить новые здания

Для первого этапа: внешний силуэт, заметная крыша, крупные проёмы и трубы, широкие скосы,
чистые цветовые пятна. Проси генератор придерживаться общей палитры и выбранного референса.
Сначала проверь модель из игровой камеры: деталь, занимающая меньше пикселя, редко полезна.

Ориентир для обычного здания без интерьера — 3–15 тысяч треугольников, 1–2 материала,
текстуры 1024–2048. Это рабочий бюджет для начала, а не гарантия FPS или предел телефона.
Наш склад сейчас имеет 3492 треугольника; мастерская — 2348, блок — 396, бочка — 268.

Большую крышу, трубу и ступень делаем геометрией. Рисунок краски, мелкую царапину и надпись
можно перенести в текстуру. Для столкновения достаточно простой невидимой коробки.
Не моделируй внутренние помещения, если игрок туда не входит и камера их не видит.

Сгенерированная модель с миллионами треугольников может быть исходником: перед игрой
её упрощают, переносят небольшие детали в текстуры и проверяют качество силуэта.
Надпись «low poly» в запросе не гарантирует нужный результат — проверяй статистику экспорта.

## Что делает генератор

`Tools/BuildTutorialDistrict.py` хранит рецепт модулей и палитру `MATERIALS`.
Для применения только палитры и текстур используй
`python Tools/BuildTutorialDistrict.py --materials-only`: mesh, планировка и сцена сохранятся.
Запуск без параметров обновляет mesh, материалы, текстуры и JSON планировки.
Он заменяет ручные изменения этих сгенерированных файлов — сначала сохрани свою работу.
`--apply-scene` дополнительно полностью пересобирает детей `MVP_TestEnvironment`;
ручная расстановка внутри этой группы будет заменена. Для обычной игры запуск не нужен.

## Проверка на телефоне

У нас по-прежнему один солнечный источник, статическое отражение, 2×MSAA и SSAO в половинном
разрешении. Этот художественный проход не добавляет новых графических проходов.
Ослабление SSAO само по себе не ускоряет его — отключение `Tutorial Contact AO` убирает проход.
Измерять FPS нужно на выбранном телефоне, в бою и после прогрева устройства.

## Превью и ограничения

`TutorialEnvironment_BeforeV4.png` и `TutorialEnvironment_V4.png` — рендеры в Blender
из фактических mesh проекта с той же камерой обзора. Они показывают прежний проход V4,
а не нынешнюю палитру V5. Blender освещает иначе, чем Unity; это не скриншоты Game View
и не доказательство точного совпадения цвета или производительности.

Проверки буферов геометрии и сохранения габаритов: `Validation/CartoonEnvironmentV4.json`.
Проверка цветов V5 и неизменности mesh, текстур и планировки: `Validation/PaletteV5Review.json`.
Проверка в Unity Editor и на телефоне остаётся обязательной перед релизом.

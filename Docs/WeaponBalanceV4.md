# Оружие и баланс — V6

Открой `Assets/IntercomMVP/Game/Weapons/Pistols/DualPistols.asset` в Unity.
Это основная карточка двух пистолетов. В ней рядом находятся баланс, профиль анимаций,
звук выстрела, трассер, вспышка и гильза. На Robot → IntercomSimpleShooter поле **Weapon**
должно ссылаться на эту карточку. Сцена уже подключена.

## Что менять

| Поле | Что происходит в игре |
|---|---|
| Damage Per Projectile | Урон **одной пули**, сейчас 15 |
| Fire Interval | Секунды между залпами, сейчас 0,18 |
| Magazine Size / Reload Seconds | Общий магазин двух пистолетов: 24 пули, перезарядка 1,15 с; запас вне магазина бесконечный |
| Barrel Mode | DualSimultaneous — два ствола одновременно; SingleAlternating — один за раз |
| Reference Target Health | HP только для расчёта в Inspector, не меняет цели на сцене |
| Projectile Speed / Range / Lifetime | Скорость, предельная дальность и время существования; пуля исчезает при первом достигнутом ограничении |
| Projectile Radius | Толщина проверки попадания |
| Tracer Width / Length | Видимый размер, независимо от столкновений |
| Parallel Projectiles | Общая текущая ось оружия для обоих стволов; отдельные точки вылета сохраняются, траектории не пересекаются крестом |
| Planar Projectile Direction | Горизонтальный полёт от настоящего конца ствола. Если предмет ниже самого ствола, пуля пройдёт над ним |
| Shot Clips / Volume / Pitch Variation | Варианты звука и громкость одного залпа |
| Flash Scale / Lifetime / Mesh / Material | Размер, длительность, форма и материал вспышки |
| Eject Casings / Casing Scale / Lifetime / Mesh / Material | Выброс, размер, длительность, форма и материал гильзы |
| Pose Profile | Профиль жестов рук и Animator Override для будущего оружия |

Базовые формы вспышки и гильзы строятся кодом. Поле Mesh позволяет заменить их своей моделью.
Материалы пула назначаются при запуске Play. После смены материала/карточки перезапусти Play.
Изменения урона, темпа и параметров нового выстрела читаются во время игры. Уже выпущенная
пуля сохраняет свой урон, скорость, радиус и размер: изменение карточки не меняет её задним числом.

## Как считается TTK

TTK — время от **первого выстрела** до поражения цели, а не самостоятельная настройка.

- Урон залпа = урон пули × число пуль в залпе.
- Число залпов = HP цели / урон залпа с округлением вверх.
- Залпов в магазине = целая часть Magazine Size / числа пуль в залпе.
- Перезарядок до поражения = целая часть (число залпов − 1) / залпов в магазине.
- Идеальный TTK = (число залпов − 1) × Fire Interval + перезарядки × max(0, Reload Seconds − Fire Interval).
- Урон/с без перезарядки = урон залпа / Fire Interval.
- Урон/с с перезарядкой = урон полного магазина / ((залпов в магазине − 1) × Fire Interval + max(Reload Seconds, Fire Interval)).

Перезарядка начинается после последнего настоящего залпа, поэтому заменяет обычный
интервал перед следующим выстрелом, а не добавляется поверх него.

Наши пистолеты: 15 × 2 = 30 урона за залп. Цель 100 HP требует 4 залпа: в 0 / 0,18 / 0,36 / 0,54 секунды.
Идеальный TTK = **0,54 с**, урон/с без перезарядки ≈166,67; длительный урон/с с перезарядкой ≈115,02. Если обе пули одного залпа попадают в разных врагов,
каждый получает только 15. Если работает один ствол, идеальный расчёт двухствольного режима не достигается.
Одно попадание, которое сразу убило цель, даёт TTK 0, поскольку отсчёт начинается с первого выстрела.

В V5 пистолеты стреляют примерно на 67% чаще, чем при интервале 0,3 с. Урон одной пули
снижен с 20 до 15: темп выше, но учебная цель не исчезает сразу от очереди. Громкость
одного залпа снижена с 0,78 до 0,68, чтобы более плотная стрельба не перекрывала остальные звуки.
При удержании огня расписание выстрелов сохраняется между кадрами: средний темп одинаков
при 30/60/120 FPS. На экране отдельный выстрел всё равно появляется на ближайшем кадре.
После большого зависания кадра игра пропускает накопившиеся выстрелы и продолжает обычный
темп; серии из нескольких выстрелов за один кадр нет.

Расчёт предполагает: оба ствола доступны, все пули попадают в одну цель, время игры и Animator
идут с обычной скоростью. Поднятие рук, полёт пули, препятствия, промахи и задержка кадра
делают реальное время больше. В V6 есть магазин и перезарядка с бесконечным запасом патронов. Броня,
критические попадания и полноценный менеджер экипировки ещё не реализованы и в расчёт не входят.

## Перезарядка

Счётчик над правым стиком показывает патроны в магазине и бесконечный запас. Нажми
на него или **R**, чтобы перезарядить неполный магазин. Пустой магазин перезаряжается
сам; держать правый стик можно, стрельба возобновится после окончания жеста.
В течение перезарядки пули и отдача не создаются. Нажатие кнопки перезарядки не
запускает стрельбу и не мешает левому стику. **Backspace** возвращает на старт.

Полностью заблокированный выстрел ничего не расходует. Если препятствие закрыло
только один ствол, расходуется одна действительно выпущенная пуля. Отключение фокуса
и пауза не пополняют магазин и не сокращают оставшееся время. Возврат на старт
восстанавливает полный магазин. При нечётной ёмкости двухствольного оружия перезарядка
начнётся, когда патронов меньше, чем нужно для полного залпа.

## Здоровье и попадание

Учебные цели используют IntercomTargetDummy, Max Health = 100. Поле настроено на самих целях.
Для будущего противника или разрушаемого объекта добавь IntercomHealth на объект с Collider
или на его родителя. Maximum Health задаёт запас здоровья. On Damaged и On Death позволяют
подключить реакцию и смерть. Сам компонент не удаляет объект: нужное поведение задаётся явно.
Не добавляй одновременно IntercomTargetDummy и IntercomHealth на одну цель.

Код оружия обращается к интерфейсу IIntercomDamageable; будущий враг может реализовать его сам.
Тип звука и частиц задаётся IntercomFootstepSurface на Collider/родителе. Название историческое:
этот компонент описывает и шаги, и попадания. Картинка текстуры не определяет тип материала.

## Будущий автомат

Сделай копию карточки, выбери SingleAlternating, задай урон и интервал. Подключи одну точку
Muzzle на автомате (локальная +Z вдоль ствола). Модель, её крепление, хват второй руки
и анимации ещё нужно подготовить. Это основа данных и стрельбы, не готовый интерфейс смены оружия.

Анимации робота хранятся внутри FBX, исходник — Source/Robot/intercom-armed.blend.
Карточка показывает связанные клипы. Pose Profile содержит ссылки **для расчёта длительности**;
сама замена клипа в Animator выполняется через Animator Override Controller в этом профиле.
При новом хвате сохрани имена состояний Arms и маску верхней части тела. Ноги остаются в базовом слое.

## Проверка

MagazineTests проверяет магазин, таймер, состояние компонента, перезарядку в реальном
расписании PoseClock при 30/60/120 FPS, захват указателей кнопкой и параллельные траектории.
WeaponFoundationTests выполняет производственный расчёт баланса, часы стрельбы, здоровье
и направление полёта. InputCancellationTests проверяет реальный драйвер позы с тестовыми
заменами Unity, включая чтение центральной карточки. PlayerAudioLifecycleTests проверяет
реальный код аудио, выбор банков, громкость и отмену при паузе. Эти тесты не заменяют
проверку Animator, Physics и звука в Unity Play Mode.

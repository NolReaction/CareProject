# Звуки попаданий V5

Громкость попаданий снижена с 0.70 до **0.42**. Сами записи заменены:

| Поверхность | Характер звука | Где проверить |
|---|---|---|
| Metal | Короткий звон металлической пластины | Первая мишень, контейнер, трансформаторы |
| Wood | Низкий сухой стук деревянного ящика | Вторая мишень, ящики |
| Concrete / Asphalt | Шершавый треск с мелкой крошкой | Третья мишень, бетонные блоки |
| Soil / Gravel | Мягкий шорох земли | Поверхности с соответствующим тегом |

Это собственные синтезированные звуки с разными резонансами и огибающими. Музыка,
записи пистолетов и тихие шаги сохранены. Общая громкость выстрелов задаётся отдельно
в `Game/Weapons/Pistols/DualPistols.asset`.

Материал берётся из **Intercom Footstep Surface** на физическом Collider или его
ближайшем родителе. Компонент обслуживает и шаги, и попадания. Цвет/текстура объекта
не переключает звук. У построенной локации тег расположен на отдельном объекте
`Collision - ...`: выбирай его, если нужно менять `Kind`, `Impact Volume` или `Impact Pitch`.
Проверены все 101 сохранённых коллайдера; у ящиков, металла и бетонных блоков разные теги.

Для быстрой проверки в игре стреляй по трём высоким мишеням слева направо:
**металл → дерево → бетон**. Очень низкий объект может оказаться ниже линии стволов;
звук возникает только при настоящем столкновении пули. Два одновременных попадания
в один материал объединяются в один звук, попадания в разные материалы сохраняются.
Количество одновременно проигрываемых звуков попаданий ограничено четырьмя.

`SoundPreviewV5.mp3` — офлайн-прослушка: 0–4 с пистолет, 4–16 с шаги, 16–24 с
попадания (**бетон → металл → дерево → земля**, по 2 с), затем общий микс с текущим
темпом стрельбы. Это проверочный микс, а не запись из Unity.

Пересоздать только попадания: `python Tools/GeneratePrototypeAudio.py --impacts-only`.
Исходник: `Tools/GenerateImpactAudio.py`; внешние семплы для этих попаданий не нужны.
Проверки: `python Validation/check_material_impacts.py` и
`python Validation/check_audio_assets.py`. Нужны Python, NumPy, SciPy и ffmpeg.
Численные проверки не заменяют прослушивание в Play Mode и на телефоне.

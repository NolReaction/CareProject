# Художественное направление CareProject

Цель — объёмный мультяшный промышленный двор с крупными понятными формами,
мягкими скосами и выразительным движением. Основные поверхности используют
спокойные серо-зелёные и серо-синие оттенки, тёплый бетон, охристую разметку
и приглушённый терракотовый контейнер. Яркий цвет оставлен для коротких
боевых эффектов и важных подсказок.

Мультяшный вид задаётся силуэтом, пропорциями, освещением и анимацией вместе.
Мелкая грязь и царапины не должны мешать видеть врага и край препятствия.
Проверяй любой новый объект из игровой камеры, а не только крупным планом.

## Где менять внешний вид

| Задача | Ресурс |
| --- | --- |
| Бетон | `Content/Environments/TutorialYard/Materials/Concrete.mat` |
| Стены, техника и бочки | `BlueGrey.mat` в той же папке |
| Крыши | `Roof.mat` |
| Контейнер | `Orange.mat` |
| Разметка и жёлтые детали | `Paint.mat` |
| Текстуры поверхности | `Content/Environments/TutorialYard/Textures` |
| Готовые модули геометрии | `Content/Environments/TutorialYard/Meshes` |
| Дневное освещение и цвет | `Settings/Rendering/Lighting/TutorialDaylight.asset` |
| Контактное затемнение | `Settings/Rendering/URP/IntercomRenderer.asset` → Tutorial Contact AO |

Пути относительны к `Assets/IntercomMVP`. Изменение общего материала влияет
на все использующие его объекты. Для индивидуальной окраски сначала создай копию.
**Tools → CareProject → Apply Tutorial Daylight** применяет профиль к открытой сцене;
после команды проверь результат и сохрани сцену.

## Новые модели

Крыша, трубы, ступени и крупные скосы формируют силуэт геометрией.
Мелкие царапины, надписи и рисунок краски лучше хранить в текстурах.
Для столкновений используй простые невидимые формы. Интерьер нужен только
там, где его действительно увидит игрок.

Сгенерированная модель с большим числом треугольников может служить оригиналом,
но игровой вариант требует проверки геометрии, материалов и размеров текстур.
Окончательный бюджет определяется сценой и измерениями на целевом телефоне.
Неиспользуемые мелкие детали и большое число материалов повышают стоимость
объекта без заметного выигрыша с игровой камеры.

Модули учебного двора уже сохранены как обычные mesh, материалы и текстуры.
Они не строятся заново на каждом кадре. Ручная правка сцены не меняет автоматически
JSON-рецепт планировки. Перед повторной генерацией сохраняй авторскую копию сцены.

Актуальная поза героя для просмотра: [Robot_Run_Poses.jpg](Robot_Run_Poses.jpg).
Это иллюстрация исходника Blender; фактический вид света и материалов проверяется
в Unity. Производительность измеряется на устройстве, включая непрерывный бой.

# Обновление CareProject V15

Для текущего проекта V14 / Git v0.2.6 (ec1b5a5).
1. Полностью закрой Unity.
2. Распакуй содержимое этого ZIP в корень проекта, где уже есть Assets, Packages и ProjectSettings, с заменой файлов.
3. Открой проект и дождись импорта/компиляции.
4. Открой Tools → CareProject → Open Scene и нажми Play: появится главное меню.

Запуск CMD или промежуточных установщиков не требуется. Файлы не перемещаются и не удаляются.
Полный самостоятельный проект поставляется отдельным архивом CareProject_Full_V15_2026-11-04.zip.

Подробности функций: Docs/Gameplay.md. Проверки: Validation/ProjectVerification.json.
Анимации и модель героя сохранены побайтно. Unity Editor в среде подготовки не запускался.

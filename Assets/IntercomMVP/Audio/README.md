# Звук V6: пистолеты, перезарядка и материалы

Главный трек **Iron Pulse** — сохранённая оригинальная композиция: 128 BPM, 48 тактов,
90 секунд. Басовый мотив, электрогитарный ответ, плотные ударные и контрастная середина.
Для инструментов использованы реальные записи под CC0; авторы и происхождение
указаны в `Source/Audio/MusicV3`. Это новая последовательность нот и аранжировка,
а не запись чужой песни. Старый Morning Shift заменён с сохранением GUID.

Пистолеты V6 пересобраны из близкой записи .45 ACP 1911 и атаки Walther PPQ:
меньше глухой низкой середины, более читаемый сухой выстрел и короткий механический
отклик. Файл длится 0,23 с. Колебания высоты — 0,8%; один звук на двойной залп.
Начало перезарядки и её завершение имеют отдельные короткие механические звуки.
Они находятся рядом с пистолетами в `Game/Weapons/Pistols/Audio`, а ссылки и
громкость Reload Volume — в карточке `DualPistols.asset`.

Тихие шаги сохранены: регулятор **0,18**. Дополнительно
смягчены сами контакты. Воспроизведение запускает фактическое приземление стопы,
включая переступание; в обычном idle и в воздухе шаги не звучат.

| Поверхность | Шаг | Попадание |
| --- | --- | --- |
| Асфальт | Мягкая шероховатая подошва | Плотный короткий скол |
| Бетон | Отдельный сухой удар с более чёткой атакой | Плотный короткий скол |
| Металл | Подошва и короткий отклик плиты | Короткий металлический звон |
| Гравий | Записанный хруст сыпучего покрытия | Глухой удар с рассыпанием |
| Дерево | Подошва и приглушённый деревянный резонанс | Сухой треск и деревянный удар |
| Земля | Мягкое приглушённое трение | Глухой удар с рассыпанием |

В V5 попадания пересозданы собственным синтезом: металл — короткие негармонические
резонансы пластины, дерево — низкий полый стук, бетон — непитчевый треск и крошка,
земля — приглушённый шум. Частотный характер и длительность различаются; это
не один звук с разной высотой. Регулятор попаданий снижен **с 0,70 в V4 до 0,42**.
Исходник — `Tools/GenerateImpactAudio.py`, внешние записи для этих попаданий не нужны.
Фон двора — тихий синтезированный воздух.

В V6 исправлены некорректные fileID у 94 сценовых компонентов материалов.
Сами банки попаданий V5 сохранены. При реальном попадании хвост выстрела кратко
приглушается, освобождая место отклику поверхности; первые 15 мс атаки сохраняются.
Параметр Shot Tail Gain On Impact = 0,55; значение 1 отключает это приглушение.
Громкость самого попадания не увеличена.

`IntercomFootstepSurface` на коллайдере или ближайшем родителе выбирает материал.
Поля `volume`/`pitch` относятся к шагам; `impactVolume`/`impactPitch` — к попаданиям.
Ближайший включённый тег имеет приоритет. Без тега попадание в мишень звучит как
металл, прочее — как бетон; при пустом специальном банке используется `impactHits`.
Пустой банк шагов возвращается к `footsteps`. Тег материала важнее типа мишени.

В `PrototypeAudio.asset`:

| Параметр | Значение |
| --- | ---: |
| Master | 0,80 |
| Shots (резерв без карточки оружия) | 0,78 |
| Steps | 0,18 |
| Impacts | 0,42 |
| Music | 0,24 |
| Ambience | 0,10 |

Для текущих пистолетов значение **Shot Volume = 0,68** берётся из
`Game/Weapons/Pistols/DualPistols.asset`; поле Shots общего профиля остаётся
резервом для оружия без карточки. Темп пистолетов — один двойной залп каждые 0,18 с.

Короткие эффекты — mono PCM 44,1 кГц, распаковка при загрузке.
Музыка — stereo Vorbis, потоковое воспроизведение. Фон — stereo 24 кГц,
сжатый в памяти. Голоса ограничены пулами: 6 выстрелов, 2 шага, 4 попадания и 1 перезарядка;
парные попадания в один материал объединяются, разные материалы звучат одновременно.

Для повторной сборки из корня проекта:

```sh
python Tools/GenerateWeaponAudio.py
python Tools/GeneratePrototypeAudio.py --impacts-only
```

Нужны Python 3, NumPy, SciPy и ffmpeg. Генераторы работают офлайн и проверяют
SHA-256 записанных исходников при полной пересборке. `--impacts-only` меняет только
попадания; `GenerateWeaponAudio.py` меняет только пистолеты и звуки перезарядки; `--sfx-only` пересобирает эффекты и фон без музыки. Без флагов пересобирается
весь набор, включая музыку.
Перед генерацией сохрани свои замены WAV/OGG. Обычное открытие Unity ничего не генерирует.

Численные проверки: `Validation/AudioGameplayV6Review.json`, `Validation/ImpactAudioV5Review.json`, музыкальные —
`Validation/MusicV3Review.json`; проверки маршрутизации и остановки —
`Validation/PlayerAudioLifecycleTests`. Повторить декодирование/смесь и обновить
превью: `python Validation/check_audio_assets.py`.
Проверить 101 коллайдер и различие фактических WAV: `python Validation/check_material_impacts.py`.
Превью `Docs/SoundPreviewV6.mp3`: 16–24 с — бетон, металл, дерево, земля по 2 с;
с 24 с — общий микс с текущим темпом. Подробности: `Docs/AudioV6.md`. Проверки с заменами Unity API не заменяют
импорт и прослушивание в Unity/на телефоне. Субъективное прослушивание здесь не выполнялось.

# Звук: Iron Pulse и материалы

Главный трек **Iron Pulse** — новая оригинальная композиция: 128 BPM, 48 тактов,
90 секунд. Басовый мотив, электрогитарный ответ, плотные ударные и контрастная середина.
Для инструментов использованы реальные записи под CC0; авторы и происхождение
указаны в `Source/Audio/MusicV3`. Это новая последовательность нот и аранжировка,
а не запись чужой песни. Старый Morning Shift заменён с сохранением GUID.

Пистолеты собраны из близкой записи .45 ACP 1911 и короткой атаки Walther PPQ:
широкий низкий удар, резкая атака, короткий естественный хвост. Колебания высоты
уменьшены до 0,8%. Один звуковой отчёт приходится на залп из двух стволов.

Шаги заметно тише предыдущей версии: регулятор **0,18 вместо 0,50**. Дополнительно
смягчены сами контакты. Воспроизведение запускает фактическое приземление стопы,
включая переступание; в обычном idle и в воздухе шаги не звучат.

| Поверхность | Шаг | Попадание |
| --- | --- | --- |
| Асфальт | Мягкая шероховатая подошва | Плотный короткий скол |
| Бетон | Отдельный сухой удар с более чёткой атакой | Плотный короткий скол |
| Металл | Подошва и короткий отклик плиты | Короткий металлический звон |
| Гравий | Записанный хруст сыпучего покрытия | Глухой удар с рассыпанием |
| Дерево | Подошва и приглушённый деревянный резонанс | Сухой треск и деревянный удар |
| Земля | Мягкое приглушённое трение | Глухой удар с рассыпанием |

Попадания созданы из записанных ударов по металлу/дереву и каменной/сыпучей
шаговой фактуры. Это звуковой дизайн; исходники не являются записями настоящих
пуль, попадающих в каждый материал. Фон двора — тихий синтезированный воздух.

`IntercomFootstepSurface` на коллайдере или ближайшем родителе выбирает материал.
Поля `volume`/`pitch` относятся к шагам; `impactVolume`/`impactPitch` — к попаданиям.
Ближайший включённый тег имеет приоритет. Без тега попадание в мишень звучит как
металл, прочее — как бетон; при пустом специальном банке используется `impactHits`.
Пустой банк шагов возвращается к `footsteps`. Тег материала важнее типа мишени.

В `PrototypeAudio.asset`:

| Параметр | Значение |
| --- | ---: |
| Master | 0,80 |
| Shots | 0,78 |
| Steps | 0,18 |
| Impacts | 0,35 |
| Music | 0,24 |
| Ambience | 0,10 |

Короткие эффекты — mono PCM 44,1 кГц, распаковка при загрузке.
Музыка — stereo Vorbis, потоковое воспроизведение. Фон — stereo 24 кГц,
сжатый в памяти. Голоса ограничены пулами: 6 выстрелов, 2 шага и 4 попадания;
два одновременных попадания одного залпа не удваивают громкость.

Для повторной сборки из корня проекта:

```sh
python Tools/GeneratePrototypeAudio.py
```

Нужны Python 3, NumPy, SciPy и ffmpeg. Генераторы работают офлайн и проверяют
SHA-256 исходников. `--sfx-only` оставляет музыкальный клип без изменений.
Перед генерацией сохрани свои замены WAV/OGG. Обычное открытие Unity ничего не генерирует.

Численные проверки: `Validation/AudioGameplayV3Review.json`, музыкальные —
`Validation/MusicV3Review.json`; проверки маршрутизации и остановки —
`Validation/PlayerAudioLifecycleTests`. Повторить декодирование/смесь и обновить
превью: `python Validation/check_audio_assets.py`. Проверки с заменами Unity API не заменяют
импорт и прослушивание в Unity/на телефоне. Субъективное прослушивание здесь не выполнялось.

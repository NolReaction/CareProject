# Звук прототипа

Все необходимые клипы уже входят в проект. Профиль `PrototypeAudio.asset` задаёт
клипы и отдельные громкости выстрелов, шагов, попаданий, окружения и музыки.
Его можно редактировать без изменения кода движения и стрельбы.

| Файлы | Назначение |
| --- | --- |
| `Pistol_01..03.wav` | Варианты выстрела |
| `BootStep_01..04.wav` | Шаги по твёрдой поверхности / асфальту |
| `BootStep_Metal_01..03.wav` | Шаги по металлу |
| `BootStep_Gravel_01..03.wav` | Шаги по гравию |
| `Impact_01..02.wav` | Попадания |
| `Ambience_IndustrialYard.wav` | Зацикленный фон двора |
| `Music_IndustrialGroove.ogg` | Зацикленная музыка |

`IntercomPlayerAudio` получает контакт стоп от `IntercomGroundFeedback`;
поверхность определяется компонентом `IntercomFootstepSurface` на коллайдере.
При недоступной калибровке используется резервная проверка физического контакта.
Музыка импортируется потоково, фон хранится сжатым в памяти, короткие эффекты
распаковываются при загрузке.

## Изменение и генерация

При замене файла сохраняй его `.meta`, чтобы ссылки из профиля продолжили работать.
После изменения профиля проверь звук в Play и на динамике телефона.

`Tools/GeneratePrototypeAudio.py` воспроизводит синтез эффектов, фона и музыку.
Для него нужны **Python 3, NumPy и ffmpeg в PATH**:

```sh
python Tools/GeneratePrototypeAudio.py
```

Скрипт перезаписывает свои именованные WAV/OGG и настройки их импорта со стабильными GUID.
Перед запуском сохрани копию собственных замен этих файлов. Генерация при открытии Unity
не выполняется. Звуки создаются из шума, осцилляторов и огибающих; внешние записи и сэмплы
генератор не загружает.

Численные проверки не подтверждают итоговый микс после импорта Unity. Прослушивание
на устройстве ещё требуется.

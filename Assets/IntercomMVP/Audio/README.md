# Звук учебного двора

В этой версии звуки заменены на обработанные **записи реальных выстрелов, шагов
и инструментов**. Источники опубликованы под CC0; авторы, ссылки и изменения
перечислены в `Source/Audio/manifest.json`. Готовые клипы уже подключены.

| Набор | Содержание |
| --- | --- |
| `Pistol_01..03.wav` | Короткие выстрелы из записи Walther PPQ: настоящая атака и затухание, три варианта, без синтетического свиста |
| `BootStep_01..04.wav` | Разные записанные контакты подошвы с твёрдым покрытием; асфальт и бетон |
| `BootStep_Metal_01..03.wav` | Та же подошва и короткий приглушённый отклик настоящего металлического предмета |
| `BootStep_Gravel_01..03.wav` | Записанный хруст сыпучего покрытия, с ограниченным шорохом после удара |
| `Impact_01..02.wav` | Короткие металлические попадания |
| `Ambience_IndustrialYard.wav` | Тихий синтезированный воздух двора, без громкого гула |
| `Music_IndustrialGroove.ogg` | **Morning Shift**: новая инструментальная композиция, 32 такта / 92 BPM / 83,5 с |

В музыке используются записанные акустическое пианино Kawai, маримба, барабаны
и шейкер. Две связанные музыкальные части и разреженный средний фрагмент меняют
плотность сопровождения. Короткие тоны прежней синтетической мелодии не используются.
Хвосты нот и отражений продолжаются через границу петли.

`PrototypeAudio.asset` управляет громкостями и включением музыки/окружения.
Вариация высоты выстрелов и шагов уменьшена до 1,2%, чтобы ботинки не пищали.
Один звуковой выстрел соответствует одному залпу из двух стволов.
Шаги привязаны к проверенному контакту стопы, поверхность задаёт
`IntercomFootstepSurface` на коллайдере. Поворотные шаги звучат тише бега.

Короткие эффекты: моно PCM, 44,1 кГц, распаковка при загрузке.
Музыка: стерео Vorbis, потоковое воспроизведение. Фон: стерео, 24 кГц,
сжатый в памяти. GUID файлов сохранены.

Для изменения звука назначай свои клипы в профиле. Для повторной сборки набора:

```sh
python Tools/GeneratePrototypeAudio.py
```

Нужны Python 3, NumPy, SciPy и ffmpeg. Генератор работает офлайн из `Source/Audio`;
перед перегенерацией сохрани собственные замены WAV/OGG. Он проверяет источники
по SHA-256 и пишет численные результаты в `Validation/Results/PrototypeAudioAssets.json`.
Обычное открытие Unity генератор не запускает.

Проверены декодирование, длительности, отсутствие цифрового клиппинга, окончания
эффектов, петля музыки и запас громкости численной смеси. Фактический импорт,
прослушивание в Unity и на телефоне ещё требуют проверки.

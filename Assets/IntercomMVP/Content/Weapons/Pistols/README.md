# Парные пистолеты

Настройки находятся в Settings/DualPistols.asset, позы — в Animation,
звуки — в Audio, материалы вспышки, гильзы и трассера — в Effects/Materials.
Tools → CareProject → Start Here открывает карточку оружия в Inspector.

Текущие значения: 15 урона на пулю; стрельба поочерёдно левым и правым
пистолетом с интервалом 0,12с; общий магазин 24; перезарядка 1,15с;
запас патронов бесконечный. Точные значения задаёт карточка, а не эта памятка.

Общая механика находится в Runtime/Combat/Weapons и Runtime/Combat/Projectiles.
Для нового оружия создавай отдельную карточку и папку ресурсов в Content/Weapons,
сохраняя существующие GUID и файл .meta при перемещении.
Конкретная модель, точки дула, хват и анимация потребуют собственной настройки.
Проект пока не содержит готовую систему инвентаря и смены оружия.

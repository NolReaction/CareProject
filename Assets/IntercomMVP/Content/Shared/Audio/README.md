# Общий звук

Settings/GameAudio.asset задаёт общий микс, музыку, фон, шаги и банки попаданий.
Шаги находятся в Footsteps, попадания по окружению — в Impacts, музыка — в Music.
Звуки пистолетов и перезарядки хранятся рядом с оружием:
Content/Weapons/Pistols/Audio. Реакции героя — Content/Characters/Robot/Audio;
попадания по противникам — Content/Enemies/Shared/Audio.

Поверхность задаётся компонентом IntercomFootstepSurface на коллайдере либо
его родителе. Kind выбирает асфальт, бетон, металл, гравий, дерево или землю;
Volume/Pitch и ImpactVolume/ImpactPitch задают множители для этого предмета.
Для противника используется отдельный банк попаданий по роботам.
Имя объекта или цвет материала сами по себе звук не переключают.

У оружия громкость, варианты выстрела и перезарядка задаются в его карточке.
Чтобы изменить шаги или музыку, начни с Tools → CareProject → Start Here → Общий звук.
Исходные записи и условия использования находятся в Source/Audio вне Assets.
Готовые звуки уже входят в проект; запуск генераторов для игры не требуется.

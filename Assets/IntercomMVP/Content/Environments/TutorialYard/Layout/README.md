# Учебный промышленный двор

DistrictLayout.json описывает расположение модулей. Сетки, материалы, текстуры
и фон находятся в соседних папках Meshes, Materials, Textures и Audio.
Готовая игровая сцена: Scenes/TutorialYard/IntercomMVP.unity.

Старт находится у южных ворот, склад — на северо-западе, мастерская — на западе,
подстанция — на северо-востоке, тренировочная площадка — на юго-востоке.
Сцена содержит свободный режим, задание на 50 роботов и спасение союзника.
Враги пока представлены капсулами; низкие предметы имеют игровые состояния.

Для замены объекта своей моделью сохраняй логический корень, компонент предмета
и коллайдер. IntercomFootstepSurface должен оставаться на коллайдере или его
родителе, чтобы шаги и попадания выбирали нужный материал. Декоративную сетку
можно заменить отдельно. Большие модели импортируй в Content/Environments.

Tools/BuildTutorialDistrict.py и BuildDistrictScene.py — инструменты генерации
модулей и сцены. Они не нужны для обычного запуска; сохраняй ручные правки
перед осознанной повторной генерацией окружения.

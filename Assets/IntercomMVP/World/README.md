# Район для тестов

Промышленная площадка 36 × 32 м: перекрёсток, объездной маршрут, склад,
мастерская, подстанция и тир с пятью неподвижными капсулами-мишенями.
В сцене есть участки для проверки звуков асфальта, металла и гравия.

## Редактирование карты

В Hierarchy раскрой `MVP_TestEnvironment`. Группы имеют `IntercomWorldAnchor`:
идентификатор, назначение и размер площадки. Меняй видимую геометрию внутри группы,
сохраняя её корень и служебные компоненты.

Объекты `Collision - ...` задают физические границы отдельно от графики.
После замены модели подгони коллайдеры. `IntercomOccluder` на корне здания объединяет
его части для прозрачности; у земли, мелкого декора и мишеней скрытие отключено.
Для типа шагов используй `IntercomFootstepSurface` на коллайдере.

У мишени коллайдер и `IntercomTargetDummy` находятся на корне, графика — в
`Visual - replace capsule`. Если меняешь графику целиком, обнови ссылки `Visual`
и `Body Renderer` в компоненте мишени.

Точки Player start, Future wave, Future pickup и Future exit резервируют места
для будущего игрового цикла и сами ничего не создают.

## Сцена и исходный план

`DistrictLayout.json` — исходные координаты блоков, зон и мишеней.
`IntercomDistrictSetup` используется при создании **отсутствующей** сцены через
**Tools → Intercom MVP → Open Scene**. Существующее окружение не удаляется.
Обычные `Setup Robot` и `Setup Mobile Prototype` не перестраивают карту.
Настройка звуков поверхностей может добавить недостающие метки и тестовые покрытия
при миграции старой сцены, сохраняя существующие здания.

Для дальнейшей работы перемещай объекты в Unity и сохраняй сцену.
Изменение JSON само по себе не перестраивает уже сохранённую сцену.

# Пистолеты: быстрый вход

Выбери `DualPistols.asset` в этой папке. Его Inspector объединяет баланс,
эффекты и звук. Чтобы быстро найти карточку, открой
**Tools → Intercom MVP → Project Guide and Balance**.

Текущая настройка V5: 15 урона на пулю, две пули в залпе, интервал 0,18 с,
громкость выстрела 0,68. Цель со 100 HP требует четыре полных залпа; идеальный TTK 0,54 с.

| Где | Что редактируется |
| --- | --- |
| `DualPistols.asset` | Урон, темп стрельбы, параметры пули и эффектов, ссылки на ресурсы; расчёт TTK |
| `Audio/Pistol_01.wav` … `Pistol_03.wav` | Варианты звука выстрела |
| `Effects/Materials/MVP_Projectile.mat` | Внешний цвет трассера |
| `Effects/Materials/MVP_Flash.mat` | Вспышка и яркая сердцевина трассера |
| `Effects/Materials/MVP_Casing.mat` | Материал гильзы |
| `Animation/DualPistolsPose.asset` | Ссылки на анимации рук и параметры переходов |

Геометрия вспышки и гильзы по умолчанию строится общим кодом
`Runtime/IntercomCombatEffects.cs`; размеры и длительность доступны в карточке оружия.
Карточка также позволяет назначать собственные меши вместо программных форм.

Сами анимационные кривые `Shoot`, `RaiseWeapons`, `LowerWeapons` пока входят
в общий `Art/Robot/IntercomRobot.fbx`. В Inspector карточки есть ссылки на эти клипы.
Они используют тот же скелет, что и бег; дублировать всего робота в папку оружия
не нужно. Редактируемый исходник находится в `Source/Robot/intercom-armed.blend`.

Общие шаги, музыка и звуки попаданий по поверхностям находятся в `Audio`.
Их используют разные виды оружия и персонажи.

## Почему в ZIP есть файлы по старым путям

Семь старых путей содержат временные, корректно импортируемые копии с другими GUID.
Это позволяет распаковать ZIP поверх V3 и повторно поверх V4/V5 без дублирования GUID.
Настоящие ресурсы в этой папке сохраняют прежние GUID, поэтому ссылки сцены продолжают работать.
После импорта редактор автоматически удаляет только точные временные копии.
Изменённую копию или копию, на которую появилась ссылка из другого ассета, он сохраняет
и показывает предупреждение. Повторить проверку можно через
**Tools → Intercom MVP → Finish Folder Upgrade**.

Общий код и пути сцены сохранены. Это папка конкретного оружия, а не вторая копия
системы управления персонажем. Общая инструкция: `START_HERE.md` в корне проекта.

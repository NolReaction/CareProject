# Дневное освещение учебного двора

TutorialDaylight.asset хранит профиль URP Volume, TutorialDaylightReflection.hdr —
отражение окружения. Солнце и Volume уже подключены в учебной сцене.
Настройки рендера находятся рядом в Settings/Rendering/URP.

Для повторного применения авторских настроек вне Play используй
Tools → CareProject → Apply Tutorial Daylight, затем сохрани сцену.
Эта команда предназначена для осознанной настройки, запускать её для открытия
готового проекта не нужно. Профиль можно открыть через Start Here.

Яркость солнца, окружающий свет, экспозиция, тени и насыщенность влияют вместе.
Оценивай результат в Game и на целевом телефоне: Scene View может иметь свои
настройки отображения. Проверка в реальном Unity Editor выполняется отдельно.

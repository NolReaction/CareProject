# Iron Pulse — оригинальная музыка CareProject

48 тактов, 128 BPM, ровно 90 секунд. Электрогитара, бас-гитара и записанная
ударная установка: ломаный ритм, короткий басовый мотив и гитарный ответ.
Это новая аранжировка из отдельных нот и ударов, без заимствованной песни,
мелодии или готового музыкального лупа. Пианино и маримба предыдущей версии
в этом треке не используются.

| Время | Развитие |
| --- | --- |
| 0–15 с | Басовый мотив, плотный ритм, постепенное появление гитарного ответа |
| 15–30 с | Полная первая тема |
| 30–45 с | Гармонический переход через C и D и возврат к E minor |
| 45–52,5 с | Разреженная середина с половинным ритмом |
| 52,5–60 с | Возвращение темы и нарастание барабанов |
| 60–75 с | Полная тема с дополнительным гитарным голосом |
| 75–90 с | Вариация и переход обратно к началу |

`Tools/GenerateMainMusic.py` содержит всю партитуру и обработку.
`generate_music(sample_rate=44100)` возвращает стереомассив; общий
`Tools/GeneratePrototypeAudio.py` использует эту функцию. Для отдельной сборки:

```sh
python Tools/GenerateMainMusic.py
```

Нужны Python 3, NumPy, SciPy и ffmpeg. Команда проверяет SHA-256 всех исходников,
перезаписывает `Music_IndustrialGroove.ogg` и `Docs/MusicPreview.mp3`.
Имя игрового файла и его Unity GUID сохранены. MP3 — отдельный 45-секундный
фрагмент с затуханием на конце; игровой OGG содержит полную циклическую музыку.
Громкость игры задаётся `Content/Shared/Audio/Settings/GameAudio.asset`, поэтому самостоятельный MP3
звучит громче музыки в игровом миксе.

## Источники записей

Использованы только 23 короткие записи (всего около 2,8 MB) из трёх библиотек
Karoryfer Samples / D. Smolken:

- [Emilyguitar](https://github.com/sfzinstruments/karoryfer.emilyguitar) — отдельные ноты электрогитары Epiphone Emily the Strange и приглушённая струна.
- [Growlybass](https://github.com/sfzinstruments/karoryfer.growlybass) — отдельные ноты Squier Jazz Bass.
- [Big Rusty Drums](https://github.com/sfzinstruments/karoryfer.big-rusty-drums) — микрофонные записи бочки, малого барабана, хай-хэта, тарелки и тома.

Официальная [страница автора](https://shop.karoryfer.com/pages/free-samples)
прямо подтверждает CC0 для этих бесплатных библиотек. Полные лицензии из
соответствующих репозиториев сохранены рядом. `manifest.json` содержит
оригинальные имена, закреплённые Git-коммиты, ссылки, исходные и локальные SHA-256.
Файлы сокращены, сведены в моно и сохранены без потерь; усиление, гитарная
перегрузка, фильтры, микротайминг и эффекты применяются генератором.

Для Growlybass фактическая нижняя нота E1 (~41,6 Hz) хранится у автора с именем
`e2`; генератор учитывает это смещение октавы. Ноты не воспроизводятся по
названию файла вслепую.

## Проверка

`Validation/MusicV3Review.json` содержит длительность, декодирование, громкость,
запас пиков и проверку повторяемости. Это численные проверки. Прослушивание
в Unity и на устройстве не выполнялось; художественное качество и удобный
баланс с выстрелами окончательно оцениваются в игре.

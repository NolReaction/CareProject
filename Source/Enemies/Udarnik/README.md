# Ударник: модель и анимации

`Udarnik_Rigged.blend` — исходник для Blender 5.2 и новее. Атлас упакован внутрь.
`Original.glb` — неизменённая присланная модель. `Poses_Preview.jpg` показывает
основные позы; подробности ремонта — в [Geometry_Notes.md](Geometry_Notes.md),
сравнение старого и нового стыка — в `Seam_Repair_Comparison.jpg`.

## Что находится в файле

В коллекции `01 Editable Robot Parts` лежат 12 отдельных деталей: `BodyShell`, `HeadCore`,
`Helmet`, `NeckJoint`, парные `UpperArm`, `Glove`, `Leg` и `Boot`.
Лицо и каска следуют общей кости `Head`; закрытые срезы и перекрывающий их
ребристый шарнир устраняют прежний разрыв. Все детали можно выбирать и
редактировать по отдельности. Группы `Part.*` сохраняют происхождение участков,
а группы с именами костей задают веса. Перчатка и предплечье остаются одним
элементом: отдельных пальцев в этой модели нет.

Общий бюджет — 7454 треугольника, 3751 вершина, 14 костей и один атлас 2048×2048.
Для Unity временные копии деталей объединяются в один `UdarnikBody` с одним
материалом. Объединение не сохраняется в исходном `.blend`.

## Анимации

| Action | Длительность | Назначение |
| --- | --- | --- |
| Idle | 1,60 с | Живая стойка с перчатками перед корпусом |
| Walk | 0,80 с | Опорные и переносные фазы, движение плеч и корпуса |
| Windup | 0,30 с | Замах; контакт приходится на конец клипа |
| Strike | 0,16 с | Продолжение удара |
| Recover | 0,48 с | Возврат в стойку |
| Hurt | 0,22 с | Короткая реакция на попадание |
| Death | 0,18 с | Запасная короткая реакция перед взрывом |
| EmergeGround | 0,95 с | Руки выходят первыми, затем робот вытягивается и встаёт |
| EmergeHatch | 1,05 с | Сложенные руки, выход через люк, шаг и распрямление |
| Emerge | 0,68 с | Совместимость со старым контроллером появления |

Шкала Blender настроена на 100 кадров/с для точных границ коротких клипов.
Это не требование частоты кадров игры. Кость `Root` остаётся неподвижной;
масштаб костей не меняется. Ботинки сохраняют соединение с голенями.
`Walk` рассчитан на 0,60345 м/с при исходной частоте воспроизведения: контроллер
связывает фазу с фактически пройденным расстоянием и меняет темп под скорость.

Подъём из земли выполняет внешний объект в Unity. Клипы задают позу, а не
перемещают игровой Root. Для `EmergeGround` подъём проходит между 12% и 86%
клипа, для `EmergeHatch` — между 4% и 90%, по плавной кривой smoothstep.
Смерть в игре скрывает модель и запускает взрыв с шестернями; постоянного
упавшего тела нет. `UdarnikBreakup.fbx` содержит шесть статических деталей
с центрами вращения для редких вариантов разлёта.

## Как редактировать

Файл сохранён с выбранным `UdarnikRig` в Pose Mode. Робот находится в центре
вида, в Action Editor выбран `Idle`. Для большой рабочей области открой вкладку
`Animation`: в ней редактор Actions имеет высоту 436 px, оба вида робота
приближены. Все кости выбраны, их каналы доступны для редактирования. Выбирай
Action в верхней строке редактора, перемещай шкалу и меняй кости. Для работы
с геометрией перейди в Object Mode и выбери нужную деталь в `01 Editable Robot Parts`.
Материалы видны в Material Preview, текстуру отдельно искать не нужно.

Сохраняй свою версию `.blend` перед изменениями. Обычные ключи здесь —
Location и Rotation; растягивать механические кости не требуется.

## Пересборка и экспорт

`BlenderTools/PrepareUdarnik.py` пересоздаёт весь производный исходник из
`Original.glb`: исправляет сетку, строит риг, создаёт десять Actions и оба FBX.
Он перезаписывает ручные изменения в `Udarnik_Rigged.blend`, поэтому сначала
сохрани свою копию. Команда из корня проекта:

```sh
blender -b --python-exit-code 1 --python BlenderTools/PrepareUdarnik.py
```

Для экспорта уже отредактированного файла без повторной генерации поз можно
в консоли Blender запустить:

```python
import importlib.util
from pathlib import Path
path = Path(bpy.data.filepath).parents[3] / 'BlenderTools/AnimateUdarnik.py'
spec = importlib.util.spec_from_file_location('udarnik_export', path)
module = importlib.util.module_from_spec(spec)
spec.loader.exec_module(module)
module.setup()
module.export_game(module.MODEL / 'Udarnik.fbx')
```

Отчёты `Validation/Reports/UdarnikGeometry.json` и `UdarnikAnimation.json`
описывают фактически выполненные проверки Blender. FBX проверен повторным
импортом в Blender; это не заменяет просмотр нативного Animator в Unity.

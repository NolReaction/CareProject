# Исходник робота и походки

## Исправление крепления ботинок, 2 ноября 2026

Ось L_Foot/R_Foot перенесена к механическому соединению ботинка
с нижней частью подшипника. Прежняя ось находилась ниже стыка,
из-за чего при вращении стопы манжета отходила от крепления.
Это отдельная проблема от сгиба носка. Геометрия и веса модели
сохранены. Подробные измерения и границы проверки приложены
в Validation/AnklePivotRepair.json и Validation/AnkleFbxRoundtrip.json.

Старые GaitAudit/LocomotionAudioReview относятся к прежнему скелету
и не подтверждают контакт стоп после этого исправления.
Не запускай прежний Tools/RebuildGroundedGait.py поверх этого исходника
без повторной проверки креплений и опоры: он создавался для старой оси.


`intercom-armed.blend` содержит редактируемую модель и 13 действий:
два Idle, восемь вариантов Run, RaiseWeapons, LowerWeapons и Shoot.
В этой версии исправлены оси стоп и вертикальная траектория в циклах бега.
Геометрия и веса сохранены; исходная поза скелета отличается положением
осей L_Foot/R_Foot. Подробности — в отчёте исправления крепления.

Открывай файл из полного клона CareProject. Шесть текстур рук/оружия упакованы
внутрь; текстуры корпуса подключены относительно `Assets/IntercomMVP/Art/Robot/Textures`.
Скрытые архивные объекты исходника не экспортируются в игру.

Для ручной правки выбери `Intercom_Armature_Fixed` и нужный Action в Action Editor.
Короткая нога состоит из Calf → Foot → Toe; коленного сустава в модели нет.
Корпус и его детали привязаны к Torso, поэтому его можно анимировать отдельно.
Не растягивай Calf масштабом: в игре дополнительная опора тоже сохраняет длину ноги.

Цикл Run длится 16 кадров при 24 FPS. Опора левой ноги: фаза 0–0,28;
правой: 0,5–0,78. Контакт пяткой сменяется плоской опорой и перекатом носка.
Темп рассчитан на `Run Reference Speed=1.2` и масштаб Robot `0.8998325` в сцене.
Idle оставлен с прежним темпом.

Для экспорта используй `BlenderTools/Export_To_Unity.py` через Scripting в Blender.
Укажи существующий `Assets/IntercomMVP/Art/Robot/IntercomRobot.fbx`, сохраняя его `.meta`.
В Unity дождись импорта; после изменений геометрии ботинок заново откалибруй
контактные маркеры через Setup Motion + Audio (сними Contact Markers Calibrated
через Debug Inspector, если менялась сама форма подошвы).

`Tools/RebuildGroundedGait.py` воспроизводит генерацию походки через Blender 5.2.
Он намеренно заменяет восемь действий Run в выходном файле, поэтому для эксперимента
задавай отдельный output.blend. Обычное открытие проекта этот скрипт не запускает.

# Исходник робота

`intercom-armed.blend` — редактируемая модель с исправленными осями ботинок.
Внутри упакованы **28 текстур**; для открытия исходника внешняя папка текстур не требуется.
Игровой FBX находится в `Assets/IntercomMVP/Art/Robot/IntercomRobot.fbx`.

Оси `L_Foot` / `R_Foot` перенесены к механическому соединению ботинка с нижней частью
подшипника. Прежняя ось находилась ниже соединения: при вращении манжета отходила от него.
Геометрия и веса сохранены; после переноса осей скорректирована вертикальная траектория бега.
Измерения исправления и повторного импорта FBX находятся в корневой папке `Validation`.

## Анимации

Сохранены 13 действий: `Idle`, `IdleRelaxed`, `Run`, `RunBackward`, `RunLeft`, `RunRight`,
`RunRelaxed`, `RunBackwardRelaxed`, `RunLeftRelaxed`, `RunRightRelaxed`,
`RaiseWeapons`, `LowerWeapons`, `Shoot`.

Для редактирования выбери `Intercom_Armature_Fixed` и нужный Action в Action Editor.
Нога устроена как **Calf → Foot → Toe**, отдельного коленного сустава нет.
Сохраняй положение стопы относительно подшипника; не имитируй опору растягиванием Calf.
Движения корпуса можно редактировать через Torso.

В Unity используются `Run Reference Speed = 1.2`, `Full Run Blend Speed = 0.45`,
`Acceleration = 8` и `Deceleration = 12`. Масштаб и скорость воспроизведения взаимосвязаны:
после изменения размеров модели повторно проверь шаги и скольжение подошв.

## Экспорт в Unity

1. Сохрани копию исходника для эксперимента, затем сохрани изменения в Blender.
2. В рабочем пространстве **Scripting** открой `BlenderTools/Export_To_Unity.py` из корня проекта
   и выполни **Run Script**.
3. В диалоге укажи `Assets/IntercomMVP/Art/Robot/IntercomRobot.fbx`.
   Экспорт работает в отдельном процессе Blender и не применяет преобразования к открытому исходнику.
4. Сохраняй существующий `.fbx.meta`: он содержит GUID, настройки импорта и привязки материалов.
5. Дождись импорта в Unity. После изменения геометрии или посадки используй
   **Tools → Intercom MVP → Fit Capsule To Idle Feet** и **Setup Robot** вне Play.
6. Если менялась форма подошвы или положение её костей, открой Debug Inspector компонента
   `Intercom Ground Feedback`, сбрось `Sole Offsets Calibrated` и `Contact Markers Calibrated`,
   затем выполни **Setup Robot** для новой калибровки. Сохрани сцену и проверь все направления бега.

Короткая нога ограничивает диапазон движения, но сама по себе не требует переделки всего робота.
Повторный автоматический генератор старой походки в проект не входит.

# CareProject: с чего начать

## Первый запуск

Распакуй полный архив в новую папку. В Unity Hub нажми **Add → Add project from disk**
и выбери папку, где рядом находятся `Assets`, `Packages` и `ProjectSettings`.
Открывай в Unity **6000.3.26f1** и дождись первого импорта. Пакеты Unity загрузятся
из реестра; дополнительная установка обновлений проекта не требуется.

При первом открытии пустого проекта учебная сцена открывается автоматически.
Ручной переход: **Tools → CareProject → Open Scene** либо двойной щелчок по
`Assets/IntercomMVP/Scenes/TutorialYard/IntercomMVP.unity`.
После импорта открой **Tools → CareProject → Проверить и восстановить проект**.
Нажми «Проверить файлы и версию». Если нужны исправления, используй
«Восстановить отсутствующие связи (с резервной копией)». Отсутствующие
Controller/Prefab ударника подготавливаются после первого импорта FBX.
Распознанный стандартный Controller V18 обновляется до десяти состояний
с резервной копией; другая назначенная модель и авторский граф сохраняются.
Восстановление повторит подготовку, если она не завершилась автоматически.
Открой готовую сцену через это окно и нажми Play.
В меню и HUD должен быть штамп **V19**. На странице «Играть» выбери
«Свободный режим», «50 роботов» или «Спасение».

Обновление предназначено для V15–V18; установщик проверяет базу перед изменением.
Для текущего проекта полностью закрой Unity. Архив обновления V19 распакуй
целиком в отдельную папку, сохранив `RepairProject.cmd`, `RepairProject.ps1`,
`Payload` и `Tools`. Запусти `RepairProject.cmd` и выбери папку своего Unity-проекта.
Установщик сначала проверяет пакет и проект, затем делает резервную копию
заменяемых файлов и убирает известные старые скрипты. После успеха открой именно
выбранный проект в Unity и выполни проверку/восстановление выше.
Копирование только папки `Payload` пропустит очистку старых определений классов.
Для чистого развёртывания используй полный архив в новой папке.

**Tools → CareProject → Start Here** — навигатор по основным карточкам,
модели, звуку, свету и документации. Кнопка «Проверить ссылки разделов»
проверяет наличие основных ресурсов.

В Start Here показано «Скомпилированная версия: V19». Если надпись другая
или её нет, сначала разберись с путём проекта и установкой исходников.
Git v0.2.7 и наличие распакованного ZIP рядом с проектом сами по себе
не подтверждают, что Unity использует новые файлы.

Окно «CareProject — проверка» позволяет проверить файлы, обновить импорт,
открыть готовую сцену и заполнить отсутствующие ссылки. Сохрани открытые сцены
и выйди из Play перед восстановлением. Резервные копии лежат в `ProjectBackups`.
Команда сохраняет существующие ссылки, позиции и параметры. Если нет самой
готовой сцены или группы комнат, возьми их из полного ZIP.

## Главное меню игры

Вкладки называются «Главная», «Играть», «Робот» и «Оружейная».
Кнопка «На выезд» на главной тоже открывает выбор режимов.
Главная страница ведёт к выбору задания, карточке робота и странице оружейной.
За интерфейсом находится временное 3D-убежище: диван с телевизором, мастерская
и оружейная. Переключение вкладок плавно переводит отдельную камеру между
ракурсами. Эти простые модели можно заменить своими, сохранив точки камеры.
В карточках показаны действующие характеристики героя и пистолетов. Закрытые
слоты — места для будущих возможностей; покупки и смена экипировки ещё не реализованы.

На главной есть рисованная зарисовка отдыхающего робота, в карточке «Спасение» —
робот с маленьким спасённым напарником. Это изображения интерфейса;
модель и анимации героя от них не меняются.

Кнопка паузы слева вверху или Escape останавливает текущий бой. «Продолжить»
или новое нажатие Escape возвращает в тот же заход. «Начать заново» после подтверждения
начинает режим заново; подтверждённый выход в главное меню завершает текущий
заход. Escape в подтверждении отменяет действие и оставляет бой на паузе.
После победы/поражения доступны повтор и переход на главную страницу.
Внутри главного меню Escape/Backspace возвращают на главную.

В бою рядом с паузой слева вверху находится здоровье, под ними — цель,
вверху по центру — время захода, справа вверху — оружие и патроны.
Нижние углы занимают большие стики. Нажми на блок патронов или R для
перезарядки. Короткие подсказки внизу по центру исчезают сами; таймер не считает
время паузы. Полноценного переключения оружия пока нет.

## Что редактировать

| Задача | Начни здесь |
| --- | --- |
| Урон, темп, магазин и перезарядка | `Content/Weapons/Pistols/Settings/DualPistols.asset` |
| Звуки, позы и эффекты пистолетов | `Content/Weapons/Pistols` |
| Модель, материалы и Animator героя | `Content/Characters/Robot` |
| Скорость и анимационные добавки | Объект Robot: Motor, Ground Feedback, Character Animation |
| Характеристики врага | `Content/Enemies/Udarnik/Settings/UdarnikCapsule.asset` |
| Модель и клипы нового ударника | `Content/Enemies/Udarnik/Model/Udarnik.fbx`; Blender в `Source/Enemies/Udarnik` |
| Смерть ударника, шестерёнки и обломки | `IntercomRobotDeathEffects` на корне миссий; код `Runtime/Enemies/Presentation` |
| Параметры режимов и частота видимых появлений | `Content/Missions` |
| Точки появления, люки и кольца предупреждения | Компоненты `IntercomEnemySpawnPoint` в сцене |
| Главная страница, робот и оружейная | Компонент `IntercomFrontEnd`; код `Runtime/Frontend` |
| Рисованные иллюстрации главной и спасения | `Content/Frontend/Artwork`; поля `homeDoodle` и `rescueDoodle` у `IntercomFrontEnd` |
| Пауза, патроны, здоровье и подсказки боя | `IntercomPlayerInput`; `Runtime/Presentation/UI` |
| Реакция предмета на попадание | `IntercomReactiveProp` → Cartoon hit feedback |
| Музыка, шаги и попадания | `Content/Shared/Audio/Settings/GameAudio.asset` |
| Планировка, материалы и модули двора | `Content/Environments/TutorialYard` |
| Свет и цвет | `Settings/Rendering/Lighting/TutorialDaylight.asset` |

Пути в таблице относительны к `Assets/IntercomMVP`. Числа и ссылки в карточках
меняй вне Play Mode, чтобы сохранить изменения.

Правила игры находятся в `Runtime`, редакторские команды — в `Editor`.
Ресурсы конкретного оружия и врага находятся в `Content`; общая механика
не дублируется вместе с каждой новой моделью.

## Blender

`Source/Robot/intercom-armed.blend` — очищенный исходник для Blender **5.2+**.
Внутри 25 Actions и 28 текстур. Рабочие клипы и дополнительные примеры движений
описаны в [Source/Robot/README.md](Source/Robot/README.md).
Готовый FBX уже находится в Unity; для первого запуска Blender не нужен.

Для нового врага есть отдельный `Source/Enemies/Udarnik/Udarnik_Rigged.blend`.
Внутри 12 отдельных деталей: HeadCore, BodyShell, Helmet, NeckJoint и парные
UpperArm, Glove, Leg, Boot с суффиксами `.L`/`.R`. Общий атлас, 14 костей и десять
Actions: Idle, Walk, Windup, Strike, Recover, Hurt, Death, Emerge,
EmergeGround и EmergeHatch. `Emerge` оставлен для совместимости.

При открытии робот должен быть виден крупно, выбран скелет в Pose Mode,
а в Action Editor — Idle и каналы костей. Для редактирования геометрии перейди
в Object Mode и выбери нужную деталь. Для анимации снова выбери `UdarnikRig`;
выбор одной сетки показывает её анимацию объекта, а не Action скелета.
Раздельный Blender нужен для удобной работы; в игровой FBX детали объединяются
только на этапе экспорта. Исходный GLB сохранён без изменений.
Это механический риг с локальным ремонтом стыка, без полной ручной ретопологии.
Инструкция: [новый ударник](Source/Enemies/Udarnik/README.md).

## Если что-то не работает

Сначала дождись окончания импорта и посмотри первую красную ошибку Console.
При пустой сцене открой рабочую сцену указанной выше командой.
Для задержки воспроизведи её, останови Play и выбери
**Tools → CareProject → Development → Performance → Open Last Capture**.

Настройки телефона находятся в **Tools → CareProject → Mobile**:
`01 Configure Controls`, `02 Android Test Settings`, `03 iPhone Test Settings`,
`04 Device Checklist`. Редкие команды подготовки моделей, NPC и света находятся
в **Advanced → Authoring**.

Сохраняй `.meta` вместе с ресурсом при переносе: он хранит GUID ссылок.
Настоящую производительность, звук, Animator и физику проверяй в Unity и на устройстве.

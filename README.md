# CareProject — Intercom MVP

Мобильный twin-stick шутер по мотивам Zombiewood: свой мир и история,
роботы вместо зомби. Горизонтальный экран, два стика, камера под наклоном.
Пока собираем удобное управление и ощущение персонажа на небольшой тестовой площадке.

## Запуск и обновление

1. В GitHub Desktop сохрани свои правки через Commit + Push. Для получения обновлений: Fetch origin → Pull origin.
2. Открой проект в Unity **6000.3.26f1**, дождись импорта.
3. Открой `Assets/IntercomMVP/Scenes/IntercomMVP.unity` и нажми Play.
   Текущая сцена уже настроена; пересоздавать её не нужно.

На компьютере: WASD / стрелки — движение; мышь + ЛКМ — прицеливание и стрельба;
пробел — альтернативная стрельба; R — возврат на старт.
На телефоне: левый стик — движение, правый — направление и огонь.

## Квартал и ощущение игры

Новая сцена — промышленный квартал **36×32 м**: центральное пересечение,
объездная петля, склад, мастерская, подстанция и тренировочный двор.
На карте стоят **пять неподвижных капсул-мишеней**. Они принимают урон,
реагируют цветом и деформацией, сплющиваются при поражении и восстанавливаются через 2,5 секунды.
Это тестовые NPC без поведения преследования.

Здания плавно становятся полупрозрачными при заметном перекрытии корпуса:
порог 45%, небольшая задержка перед включением, 25% оставшейся непрозрачности.
Мелкий декор и низкие укрытия остаются видимыми. Коллизии продолжают работать.

Пули ускорены с 16 до **36 м/с**; яркая головка и хвост читаются на игровой камере.
Добавлены вспышки, вылет вращающихся гильз с отскоками и искры попаданий.
Проверка пути пули выбирает ближайшее препятствие, включая тонкие стены.

У подошв появились мягкие контактные тени и короткие пылевые следы.
Корпус получает небольшое покачивание по направлению бега, акцент шага и отдачу.
Это дополнительное движение поверх существующих клипов; исходный FBX не менялся.
Скорость персонажа остаётся 1,8 м/с; полноценного foot IK пока нет.

Выстрелы, шаги и фон переработаны: более короткий мультяшный хлопок с механическим
откликом, плотный звук подошвы, мягкий ветер и гул. Добавлены варианты попаданий.
Звуки синтезированы специально для прототипа, весь набор WAV меньше 1 МБ.

## После Pull

1. Открой обновлённую `IntercomMVP.unity`. В сохранённой сцене уже подключены карта,
   мишени, звук и эффекты. Дождись импорта и нажми Play.
2. Если используешь свою копию старой сцены: вне Play нажми
   **Tools → Intercom MVP → Setup District Prototype**, затем Ctrl+S.
   Команда обновляет старую тестовую площадку и соединяет компоненты.
   Установленный квартал помечен версией: повторный запуск сохраняет твои дальнейшие изменения.
3. Пробеги вдоль края здания: лёгкое перекрытие ботинка или оружия не должно включать
   прозрачность. При заходе за здание корпус должен оставаться читаемым.
4. Постреляй в капсулы и стены. Проверь вспышки, быстрые пули, гильзы, попадания и
   восстановление мишеней. Попробуй выстрел через тонкую стену и вплотную к препятствию.
5. Посмотри на шаги с игровой камеры и сбоку: контактные тени должны оставаться на
   поверхности, ослабевать под поднятой ногой; пыль появляется только в движении по земле.
6. Проверь оба стика, бег спиной/боком, сворачивание игры и возвращение.
   На телефоне отдельно оцени частоту кадров и громкость через динамик.

## Настройки

Меняй параметры вне Play Mode и сохраняй сцену.

| Что | Где |
|---|---|
| Скорость робота | Robot → Intercom Player Motor → Move Speed |
| Темп исходного цикла | Run Reference Speed = 0.8 |
| Скорость и вид пуль | Robot → Intercom Simple Shooter → Projectile Speed / Radius / Tracer Length |
| Гильзы и вспышки | Robot → Intercom Combat Effects |
| Контактные тени и движения корпуса | Robot → Intercom Ground Feedback |
| Порог и плавность прозрачности | Main Camera → Intercom Camera Occlusion |
| Звуки, громкости и контакт шага | `Assets/IntercomMVP/Audio/PrototypeAudio.asset` |
| Частота стрельбы и удержание оружия | `Assets/IntercomMVP/Animation/DualPistolsPose.asset` |
| Ракурс | Main Camera → Intercom Camera Follow → Capture Scene View / Capture Current Camera |
| Посадка после изменения модели | Tools → Intercom MVP → Fit Capsule To Idle Feet |

## Как заменять модели карты

В Hierarchy раскрой **MVP_TestEnvironment**: части района подписаны и имеют
`IntercomWorldAnchor` с назначением и размером площадки. Заменяй визуальные объекты
внутри нужной группы; отдельные дочерние **Collision** содержат коллайдеры.
Подгоняй эти коллайдеры под новую форму. Метка `IntercomOccluder` на корне здания
объединяет его части для прозрачности. Для земли, декора и мишеней она выключена.

У мишени замени дочернюю группу **Visual - replace capsule**, затем назначь
Visual и Body Renderer в `IntercomTargetDummy`. Коллайдер и поведение лежат на корне.
Точки маршрутов, границы зон и места объектов — основа будущего наполнения;
логика волн, задания и навигация NPC будут следующим этапом.
План района и описание групп лежат в `Assets/IntercomMVP/World`.

Следующий игровой этап: один подвижный противник, здоровье игрока, волна и перезапуск.

## Проверки кода

В `Validation` есть самостоятельные .NET 8 тесты; например:
`dotnet run --project Validation/AudioTimingTests/AudioTimingTests.csproj`.
Отчёты описывают границы каждой проверки. Unity Editor и устройство в среде автора правок
недоступны: компиляция в Unity, реальная физика, прослушивание микса и сборка на телефон
должны быть проверены после Pull. Численные тесты не заменяют Play Mode.

# CareProject — учебный промышленный двор

Unity **6000.3.26f1**, Universal Render Pipeline **17.3.0**.
База обновления: коммит `3dd9354b44b343cd489a5dcf4223e38859a86ed9` («исправил 1.0»).

## Установка ZIP в рабочий проект

1. Закрой Unity, чтобы открытая старая сцена не перезаписала обновлённый файл.
2. Распакуй содержимое ZIP **в корень своего CareProject с заменой файлов**.
   Папка `Assets` из архива должна объединиться с существующей `Assets`;
   рядом находятся `Packages`, `ProjectSettings`, `Source` и `README.md`.
3. Открой проект через Unity Hub в 6000.3.26f1 и дождись импорта.
4. Открой `Assets/IntercomMVP/Scenes/IntercomMVP.unity` и нажми Play.
   Сцена, модель, материалы, звук и свет уже соединены; команды Setup для запуска не нужны.

Первый импорт очищает известные устаревшие файлы прошлых версий по списку
`Assets/IntercomMVP/Editor/LegacyCleanup.json`. Изменённые вручную файлы сохраняются.
Пустые замены двух старых скриптов сначала выключают их автоматические изменения сцены.
Ни установка, ни скрипты проекта ничего не отправляют в GitHub.

## Что входит в эту версию

- Поворот на месте: верх корпуса начинает движение, ноги догоняют отдельными шагами.
  Ограничение поворота верха удерживает его рядом с направлением опоры.
- Бег: согласованные длина шага и темп, более заметный взмах рук, мягкое отставание пружин,
  постановка пятки и переход к отталкиванию носком. Крепление ботинок сохраняет длину связей.
- Записанные звуки пистолета и поверхностей вместо прежних синтетических эффектов;
  новая инструментальная музыка. Исходники и происхождение записей находятся в `Source/Audio`.
- Карта по концепту промышленного двора: склад, мастерская, подстанция, центральные укрытия,
  обходы и тир. Детали собраны из общих игровых мешей; крупные объекты можно заменить своими.
- Дневной свет: тёплое солнце, прохладный рассеянный свет, отражения, ACES и контактное затенение.

На компьютере: WASD / стрелки — движение, мышь + ЛКМ — прицеливание и стрельба,
пробел — стрельба, R — возврат на старт. На телефоне: левый стик — движение,
правый — поворот и огонь. Тир использует неподвижные мишени с восстановлением.

## Где редактировать

| Задача | Место |
| --- | --- |
| Скорость, разгон и темп шага | Robot → Intercom Player Motor |
| Переступание, опора и инерция корпуса | Robot → Intercom Ground Feedback |
| Громкости музыки, шагов и стрельбы | `Assets/IntercomMVP/Audio/PrototypeAudio.asset` |
| Цветокоррекция | `Assets/IntercomMVP/Settings/TutorialDaylight.asset` |
| Контактное затенение / его отключение | `Assets/IntercomMVP/Settings/IntercomRenderer.asset` → Tutorial Contact AO |
| Солнце | Directional Light в сцене |
| Камера | Main Camera → Intercom Camera Follow; кнопки Capture в инспекторе |
| Замена зданий и предметов | [World/README](Assets/IntercomMVP/World/README.md) |
| Исходник и экспорт робота | [Source/Robot/README](Source/Robot/README.md) |
| Звуковые исходники | [Audio/README](Assets/IntercomMVP/Audio/README.md) |

Команды **Tools → Intercom MVP** предназначены для осознанной настройки других сцен:
Open Scene, Setup Robot, Setup Mobile Prototype, Fit Capsule To Idle Feet, Texture Setup,
Apply Tutorial Daylight и настройки Android/iPhone. После изменений вне Play сохраняй сцену.
Построители карты и анимаций не запускаются при обычном открытии проекта.

В `Docs` находятся превью: `TutorialEnvironment.png` — геометрия нового двора,
`MotionPolishComparison.mp4` — сравнение бега, `SoundPreview.mp3` и `MusicPreview.mp3` —
новые звуки и музыка. Визуальные превью сделаны в Blender, окончательный вид проверяй в Unity.

логики с заменами API и Blender-превью не подтверждают фактический импорт, Animator/PhysX,

# CareProject — Intercom MVP

Мобильный twin-stick шутер по мотивам Zombiewood: свой мир и история,
роботы вместо зомби. Горизонтальный экран, два стика, камера под наклоном.
Пока собираем удобное управление и ощущение персонажа на небольшой тестовой площадке.

## Запуск и обновление

1. В GitHub Desktop сохрани свои правки через Commit + Push. Для получения обновлений: Fetch origin → Pull origin.
2. Открой проект в Unity **6000.3.26f1**, дождись импорта.
3. Открой `Assets/IntercomMVP/Scenes/IntercomMVP.unity` и нажми Play.
   Текущая сцена уже настроена; пересоздавать её не нужно.

На компьютере: WASD / стрелки — движение; мышь + ЛКМ — прицеливание и стрельба;
пробел — альтернативная стрельба; R — возврат на старт.
На телефоне: левый стик — движение, правый — направление и огонь.

## Текущие изменения

- Скорость поднята с **0,8 до 1,8 м/с**. Темп бега учитывает фактическое движение;
  стояние сохраняет обычную скорость. Бег вперёд, назад и вбок использует прежние клипы.
- Исправлена устаревшая посадка CharacterController: его нижняя точка была примерно
  на **3,7 см ниже подошв**. Капсула совмещена с текущим Idle, стартовый объект опущен к земле.
- Подключены три варианта выстрела, четыре варианта шага и тихий фон двора.
  Выстрел звучит при создании пули; шаги зависят от цикла анимации, реальной скорости и земли.
  При упоре в стену, потере фокуса и паузе лишние шаги не накапливаются.
- Общий профиль звука позволяет менять клипы и баланс без правки кода.
  Звуки синтезированы для прототипа; окончательный характер и громкость проверяем на слух.

## Где настраивать

Меняй параметры вне Play Mode и сохраняй сцену/проект.

| Что | Где |
|---|---|
| Скорость | Robot → Intercom Player Motor → **Move Speed**, сейчас 1.8 |
| Соотношение шага и движения | **Run Reference Speed**, сейчас 0.8 — скорость, под которую создан исходный цикл |
| Звуки и громкость | `Assets/IntercomMVP/Audio/PrototypeAudio.asset`: Master, Shots, Steps, Ambience Volume; массивы клипов |
| Момент звука шага | В том же профиле **Footstep Phase Offset**; контакты примерно 0 и 0.5 цикла |
| Частота стрельбы и удержание оружия | `Assets/IntercomMVP/Animation/DualPistolsPose.asset` |
| Ракурс камеры | Main Camera → Intercom Camera Follow → Capture Scene View / Capture Current Camera |
| Перепривязать звук | Tools → Intercom MVP → Setup Prototype Audio, затем Ctrl+S |
| Пересчитать посадку после изменения модели | Tools → Intercom MVP → Fit Capsule To Idle Feet, затем Ctrl+S |

Кнопка Setup Mobile Prototype также подключает звук и движение; сохраняет назначенный
профиль звука и его баланс. Для новых объектов зданий ставь `IntercomOccluder` на общий корень,
чтобы камера скрывала всё здание, когда оно закрывает персонажа.

## Проверка после Pull

1. Пробеги в четыре стороны, по диагонали и спиной во время стрельбы.
   Отпусти движение: остановка и Idle должны быть обычными, без замедленного стояния.
2. Посмотри на подошвы сбоку в Scene во время Play: на ровном полу нет постоянного зазора.
   Небольшие различия при смешивании направлений ещё возможны — полноценного foot IK пока нет.
3. Послушай шаги; упрись в стену и постой. На месте топот должен прекращаться.
4. Стреляй короткими касаниями и удержанием. Звук начинается после подъёма оружия,
   одновременно с пулей. Если обе пули блокирует стена у стволов, звука выстрела нет.
5. Сверни игру и вернись: старые выстрелы не продолжаются, фон возвращается плавно.
6. На телефоне проверь оба стика одновременно, горизонтальную ориентацию и баланс
   громкости через динамик. Android: Tools → Intercom MVP → Configure Android Test Settings,
   затем сборка для своего устройства; необходимые Android-модули ставятся через Unity Hub.

## Основа для следующего этапа

Уже есть управление, камера, скрытие зданий, направленная анимация, состояния оружия,
пул пуль и ограниченный пул звуков. Пока нет противников, урона, здоровья, победы/поражения
и полноценного игрового цикла. Следующий небольшой этап: одна мишень/робот-противник,
попадание с откликом и здоровьем, затем одна тестовая волна и перезапуск.

Для будущего оружия позы живут в `IntercomWeaponPoseProfile`, звуки — в `IntercomAudioProfile`.
`IntercomSimpleShooter.VolleyFired` сообщает об успешном залпе и может подключать другие эффекты.
Фон пока общий для сцены; отдельные звуковые зоны добавим, когда появится полноценная локация.
Исходный Blender-файл хранится отдельно; текущий FBX и `.meta` уже в Git.

## Проверки кода

В `Validation` есть самостоятельные .NET 8 тесты; например:
`dotnet run --project Validation/AudioTimingTests/AudioTimingTests.csproj`.
Отчёты описывают границы каждой проверки. Unity Editor и устройство в среде автора правок
недоступны: компиляция в Unity, реальная физика, прослушивание микса и сборка на телефон
должны быть проверены после Pull. Численные тесты не заменяют Play Mode.

# CareProject V22 / 0.3.3

Полный проект Unity **6000.3.26f1**, Universal Render Pipeline **17.3.0**.
Шутер с двумя стиками, учебным промышленным двором и режимами «50 роботов»,
«Спасение» и свободной тренировкой.

## Запуск

1. Распакуй полный ZIP в новую папку.
2. В Unity Hub выбери **Add → Add project from disk** и папку с `Assets`,
   `Packages` и `ProjectSettings`.
3. Открой проект в Unity **6000.3.26f1**. Дождись импорта и загрузки пакетов.
4. Открой сцену `Assets/IntercomMVP/Scenes/TutorialYard/IntercomMVP.unity`.
5. Нажми Play. В меню и HUD должна отображаться версия **V22**.

После импорта редактор автоматически обновляет стандартный контроллер ударника
до 18 состояний, сохраняя GUID и резервную копию предыдущего графа.
Если Console сообщает об отложенной подготовке, открой
**Tools → CareProject → Проверить и восстановить проект** и восстанови связи.
Авторский нестандартный граф и другая назначенная модель автоматически не заменяются.

## Изменения V22

- Анимированный HUD здоровья: плавная полоса, отложенный след потерянного HP,
  реакция на удар и отдельный зелёный акцент лечения.
- Мягкая подсветка краёв экрана и пульсация при критическом здоровье.
- Подбираемые аптечки на земле: **+35 HP**, ограничение максимальным здоровьем;
  при полном HP предмет не расходуется. После перезапуска миссии аптечки возвращаются.
- Подробности и маршрут проверки: [CHANGELOG_V22.md](CHANGELOG_V22.md).

## Сохранённые изменения V21

- Разворот ударника исправлен отдельно от направления движения и зоны удара;
  заданный поворот префаба сохраняется.
- 18 настоящих клипов: отдельный бег, прямой удар, боковой удар, удар сверху,
  усиленная реакция на попадание и разные появления из земли и люка.
- Непрерывные волны без межволновых и групповых передышек. Следующая волна
  начинает поступать, пока предыдущие противники ещё живы.
- В «50 роботов» квоты 10 / 14 / 18 / 8, одновременно 5 → 6 → 7 → 8 врагов;
  интервал появления постепенно уменьшается с 1,0 до 0,66 секунды.
- Подбираемые золотые шестерёнки выпадают из роботов и сломанных предметов:
  разлёт, отскок, вращение, притягивание рядом с героем, счётчик под таймером.
- Запчасти за врагов начисляются по реально собранным шестерёнкам. Бонусы
  за выполнение задания сохранены; оставшиеся выпавшие шестерёнки при победе
  включаются в итог, чтобы награда последнего врага не терялась.

История предыдущей версии: [CHANGELOG_V21.md](CHANGELOG_V21.md).

## Управление

ПК: WASD/стрелки, мышь и удержание ЛКМ для огня, R для перезарядки,
Escape для паузы. На телефоне: движение левым стиком, прицел и огонь правым.
Пауза по желанию игрока сохранена.

## Файлы и разработка

- `Assets/IntercomMVP/Runtime`: игровой код.
- `Assets/IntercomMVP/Content`: готовые модели, материалы, миссии, звук.
- `Source/Enemies/Udarnik/Udarnik_Rigged.blend`: редактируемый враг и 18 Actions.
- `BlenderTools/AnimateUdarnik.py`: воспроизводимая подготовка анимаций и FBX.
- `Validation`: автономные проверки логики и отчёт `ProjectVerification.json`.
- [START_HERE.md](START_HERE.md): первый запуск и перенос.

ZIP содержит весь проект; старая поставка для запуска не требуется.
Никакие изменения этой поставки не отправлялись в GitHub.
Unity Editor и сборка на телефоне в среде подготовки не запускались;
проверки C# с заменами Unity API и Blender не заменяют настоящий Play Mode.

# CareProject — доработка V6

Unity **6000.3.26f1**, Universal Render Pipeline **17.3.0**.
База GitHub: коммит `194c84599e6681bed83a5b01c19f714118095d00` (`v0.2.1`).
Это загруженная владельцем V5 с его изменением Gravel.mat; материал сохранён.

**Начни с [START_HERE.md](START_HERE.md): установка, настройки, баланс и подготовка автомата.**

## Установка

Закрой Unity. Распакуй ZIP в корень CareProject с заменой файлов: `Assets` объединяется
с существующей `Assets`; рядом находятся `Packages` и `ProjectSettings`.
Открой проект и дождись импорта. Запусти `Assets/IntercomMVP/Scenes/IntercomMVP.unity`.
Учебная сцена уже подключена; запуск Setup для неё не требуется.

Ресурсы пистолетов перенесены с сохранением GUID. Временные файлы по старым путям
удаляются после импорта только при точном совпадении и отсутствии ссылок.
Ни обновление, ни скрипты проекта ничего не отправляют в GitHub.

## Что изменено в V6

- Исправлено пересечение траекторий двух пистолетов: общее направление, разные стволы.
- Магазин на 24 патрона, бесконечный резерв, автоматическая и ручная перезарядка 1,15 с.
  Счётчик и кнопка на экране; на клавиатуре R. Backspace возвращает на старт.
- Стабилизация корпуса при беге, более быстрые повороты на месте, жесты перезарядки,
  ожидания и прижимания рук у близкой стены.
- Новые записи пистолетов и звуки перезарядки. Исправлены 94 некорректных ID
  компонентов поверхностей; проверены связи всех 101 коллайдера с материалами.
- Проверка сцены теперь обнаруживает выход ID за допустимый диапазон и потерянные ссылки.

Исходная модель робота, FBX, музыка, планировка и спокойная палитра сохранены.
Новые жесты накладываются кодом поверх имеющихся клипов: они не являются новыми Actions
в исходном Blender. Отдельного автомата в архиве нет.

## Управление

WASD / стрелки — движение, мышь + ЛКМ — прицеливание и стрельба, пробел — стрельба,
R — перезарядка, Backspace — возврат на старт. На телефоне левый стик перемещает, правый направляет оружие
и стреляет. Учебные мишени восстанавливаются после уничтожения.

## Проверено и ограничения

`Validation/FoundationV6Review.json` содержит результаты именно этой версии.
Отчёты V5, V4, V3 и предыдущих проходов относятся к своим версиям.
`Docs/TutorialEnvironment_V4.png` — историческое Blender-превью геометрии V4.
Оно не показывает новую палитру V5 и не является скриншотом Unity.

Unity Editor и Android-устройство в среде подготовки недоступны. Проверки C# с
тестовыми заменами движка, целостности ресурсов и геометрии не подтверждают фактическую
компиляцию в Unity, Play Mode или FPS на телефоне. Эти шаги нужны после импорта.

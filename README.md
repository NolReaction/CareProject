# CareProject — доработка V5

Unity **6000.3.26f1**, Universal Render Pipeline **17.3.0**.
Продолжение выданного архива V4. База GitHub: коммит `c0f3ef82077151c3a28945e25e5bc04103411e9d` («Исправления»).

**Начни с [START_HERE.md](START_HERE.md): установка, настройки, баланс и подготовка автомата.**

## Установка

Закрой Unity. Распакуй ZIP в корень CareProject с заменой файлов: `Assets` объединяется
с существующей `Assets`; рядом находятся `Packages` и `ProjectSettings`.
Открой проект и дождись импорта. Запусти `Assets/IntercomMVP/Scenes/IntercomMVP.unity`.
Учебная сцена уже подключена; запуск Setup для неё не требуется.

Ресурсы пистолетов перенесены с сохранением GUID. Временные файлы по старым путям
удаляются после импорта только при точном совпадении и отсутствии ссылок.
Ни обновление, ни скрипты проекта ничего не отправляют в GitHub.

## Что изменено в V5

- Бег 3,3 м/с вместо 2,1; более быстрые разгон, остановка и реакция камеры.
  Шаг расширяется вращением существующей ноги без растягивания костей.
- Пистолеты: залп каждые 0,18 с, 15 урона каждой пули. Идеальный TTK по 100 HP — 0,54 с.
- Более спокойные материалы двора и дневной свет, без усиления насыщенности.
- Заново сделанные тихие попадания: звон металла, глухой удар дерева, крошка бетона.
- Проверка перекрытий по мешу перед корпусом робота; соседние предметы не скрываются
  автоматически вместе с целым кварталом.

Текущая музыка и модель робота с 13 клипами сохранены. Нового автомата и его хвата
в архиве нет: эти ресурсы подготавливаются отдельно. Боезапас пока бесконечный.

## Управление

WASD / стрелки — движение, мышь + ЛКМ — прицеливание и стрельба, пробел — стрельба,
R — возврат на старт. На телефоне левый стик перемещает, правый направляет оружие
и стреляет. Учебные мишени восстанавливаются после уничтожения.

## Проверено и ограничения

`Validation/FoundationV5Review.json` содержит результаты именно этой версии.
Отчёты V4, V3 и предыдущих проходов относятся к своим версиям.
`Docs/TutorialEnvironment_V4.png` — историческое Blender-превью геометрии V4.
Оно не показывает новую палитру V5 и не является скриншотом Unity.

Unity Editor и Android-устройство в среде подготовки недоступны. Проверки C# с
тестовыми заменами движка, целостности ресурсов и геометрии не подтверждают фактическую
компиляцию в Unity, Play Mode или FPS на телефоне. Эти шаги нужны после импорта.

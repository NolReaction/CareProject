# CareProject — Intercom MVP

Мобильный twin-stick прототип: робот, промышленный квартал, пять мишеней,
стрельба, контакт стоп, звуки поверхностей и музыка. Проект использует Unity **6000.3.26f1**.

## Как открыть исправленную версию

1. Распакуй **полный ZIP проекта в новую пустую папку**. Не накладывай его на старый проект
   и не смешивай файлы из предыдущих архивов с отдельными исправлениями.
2. В Unity Hub выбери **Add → Add project from disk** и укажи папку, внутри которой
   находятся `Assets`, `Packages` и `ProjectSettings`.
3. Открой её в **6000.3.26f1** и дождись импорта пакетов и ресурсов.
4. Открой `Assets/IntercomMVP/Scenes/IntercomMVP.unity`, затем нажми **Play**.
   Готовая сцена уже настроена; запускать установщики для первого запуска не требуется.

Старый проект оставь отдельной резервной копией. Переносить свои последующие изменения
лучше после проверки этой версии, сохраняя `.meta` соответствующих ресурсов.

На компьютере: **WASD / стрелки** — движение, **мышь + ЛКМ** — прицеливание и стрельба,
**пробел** — альтернативная стрельба, **R** — возврат на старт.
На телефоне: левый стик — движение, правый — направление и огонь.

## Что исправлено

- Скрипты движения, контакта стоп, звука и редакторской настройки сведены к одной версии.
- Оси `L_Foot` / `R_Foot` находятся в соединении ботинка с подшипником.
  Исправлены FBX и редактируемый `.blend`; геометрия и веса сохранены.
- Калибровка подошв учитывает версию осей и измеряет текущую позу Idle.
  Пока калибровка не готова, зависимые контактные эффекты не используют старые координаты.
- Все текстуры входят в проект; сохранены 13 клипов анимации.
- Удалены старый генератор площадки, разовая автоматическая правка видимости оружия,
  повторяющиеся команды и применённые миграционные скрипты.
- Настройка робота сохраняет размещённую камеру. Настройка мобильного режима
  не перестраивает район; автоматического пересоздания сцены нет.

## Настройки персонажа

Меняй значения вне Play и сохраняй сцену (`Ctrl+S`).

| Что | Где / значение этой версии |
| --- | --- |
| Скорость | Robot → Intercom Player Motor → Move Speed: `1.8` |
| Разгон / торможение | Acceleration: `8`, Deceleration: `12` |
| Темп цикла бега | Run Reference Speed: `1.2` |
| Переход к полному циклу | Full Run Blend Speed: `0.45` |
| Контакт подошвы, пыль и движения корпуса | Robot → Intercom Ground Feedback |
| Выстрелы и снаряды | Robot → Intercom Simple Shooter / Intercom Combat Effects |
| Звуки и музыка | `Assets/IntercomMVP/Audio/PrototypeAudio.asset` |
| Ракурс | Main Camera → Intercom Camera Follow |
| Прозрачность зданий | Main Camera → Intercom Camera Occlusion |

Для ракурса используй **Capture Scene View** или **Capture Current Camera** в инспекторе
камеры. Кнопка **Keep Follow Settings After Play** переносит выбранные параметры камеры
после остановки Play; затем сохрани сцену.

## Команды редактора

Все команды находятся в **Tools → Intercom MVP**.

| Команда | Назначение |
| --- | --- |
| Open Scene | Открыть готовую сцену; создать новую только если файл сцены отсутствует |
| Setup Robot | Подключить движение, оружие, контакт стоп и звук в текущей сцене с корневым Robot |
| Setup Mobile Prototype | Подключить робота, камеру и мобильные настройки; зарегистрировать текущую сцену для сборки |
| Fit Capsule To Idle Feet | Подогнать CharacterController к ногам после изменения модели |
| Texture Setup | Проверить изображения и восстановить материалы / привязки FBX |
| Configure Android Test Settings | Подготовить параметры локального Android-теста |
| Configure iPhone Test Settings | Подготовить параметры локального iPhone-теста |

`Setup Robot` сохраняет существующие компоненты и пользовательские настройки,
кроме точечных миграций прежних стандартных значений. Команды настройки не сохраняют
сцену автоматически: после осознанных изменений нажми `Ctrl+S`.

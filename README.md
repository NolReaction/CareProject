# CareProject

Полный проект Unity: шутер с двумя стиками, роботом, учебным промышленным двором,
режимами «50 роботов», «Спасение» и свободным режимом без AI.
Версия поставки — **V15**. Unity **6000.3.26f1**, Universal Render Pipeline **17.3.0**.

## Открыть проект

1. Распакуй весь ZIP в новую папку.
2. В Unity Hub выбери **Add → Add project from disk** и укажи папку,
   внутри которой находятся `Assets`, `Packages` и `ProjectSettings`.
3. Открой проект в Unity **6000.3.26f1**. Дождись загрузки пакетов, импорта
   ресурсов и компиляции. При первом открытии для пакетов нужен интернет.
4. После импорта откроется учебная сцена. Если редактор показывает пустую сцену,
   выбери **Tools → CareProject → Open Scene**.
5. Нажми кнопку Play редактора. В главном меню игры открой «Играть» и выбери
   режим. Для знакомства подойдёт «Свободный режим».

Это самостоятельный проект. Запускать CMD, устанавливать предыдущие версии
или переносить файлы из старого проекта не требуется. Папку `Library` Unity
создаст сама при первом открытии.

Рабочая сцена: `Assets/IntercomMVP/Scenes/TutorialYard/IntercomMVP.unity`.
Навигатор разработчика: **Tools → CareProject → Start Here**.

## Управление

На телефоне левый стик двигает героя, правый задаёт прицел и огонь.
На компьютере: WASD/стрелки — движение, мышь и удержание левой кнопки — огонь,
R — перезарядка, Escape — меню игры. Экранные элементы работают и мышью.

## Что есть в этой версии

Главное меню разделено на главную страницу, выбор режима, робота и оружейную.
Вкладки робота и оружия показывают текущие характеристики; закрытые места
обозначают будущее расширение. Покупок, экономики и смены экипировки пока нет.
Ударники медленнее преследуют героя и некоторое время помнят последнее
увиденное место. Часть появлений происходит через люки и из земли с предупреждением.
Попадания по интерактивным предметам дают короткую деформацию и красную подсветку,
металл звучит короче, а видимые гильзы стали крупнее и появляются реже.

Подробнее о поведении и настройках: [Gameplay.md](Docs/Gameplay.md).

## Папки

| Папка | Содержимое |
| --- | --- |
| `Assets/IntercomMVP/Runtime` | Код игры по системам; `Frontend` — главное меню |
| `Assets/IntercomMVP/Editor` | Инструменты Unity и навигатор |
| `Assets/IntercomMVP/Content` | Герой, пистолеты, враги, миссии, учебный двор, звук и эффекты |
| `Assets/IntercomMVP/Scenes` | Игровая сцена |
| `Assets/IntercomMVP/Settings` | URP и дневное освещение |
| `Source/Robot` | Очищенный редактируемый Blender с упакованными текстурами |
| `Tools`, `BlenderTools` | Инструменты подготовки ресурсов вне игры |
| `Docs`, `Validation` | Документация, исходники проверок и текущий отчёт |
